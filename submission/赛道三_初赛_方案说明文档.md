## 一、所选方向与科学问题理解

### 1.1 方向定位

本方案对标**方向一「虚拟细胞」**首期赛题——*虚拟酵母扰动响应预测*：基于酿酒酵母扰动蛋白质组数据，预测**未见化合物、未见菌株及二者组合**条件下的完整蛋白质组响应，考察模型对未知条件的外推与泛化能力。

我们把该任务抽象为更一般、也更贴近赛题科学初心的命题：

> **在组合扰动空间上预测响应，并对"未见条件"给出可信的不确定度，使预测能直接进入"AI 预测 → 湿实验验证"闭环。**

这恰好是方向一科学意义所述"菌株定向改造与优化"的数据支撑环节，也是本赛道反复强调的三条硬约束的落点：**区分记忆与机制泛化**（OOD 子集评测）、**评测须含未见条件**（未见动作 / 未见主体 / 新神经调质三组 OOD 子集）、**报告须给不确定度**（保角校准 + 后验 epistemic）。

### 1.2 核心科学问题：epistemic 不确定度的 OOD 欠缩放（PC-3）

扰动响应预测真正稀缺的不是"拟合能力"，而是**外推时的不确定度可信度**。我们对标任务的基准复现（P1 臂，见 §三）暴露出一个结构性缺口，我们称为 **PC-3（epistemic under-scaling）**：

- 在标准训练-校准-测试流程下，模型在**分布内（ID）**可达到标称覆盖，但其 epistemic 不确定度 σ(x) **不随"到训练流形的距离" τ(x) 单调增长**（应 ∂σ/∂τ > 0，现实在 OOD 区 σ 塌缩）；
- 后果：在**未见条件**（新化合物 / 新菌株 / 新调质）下，σ 严重**欠缩放**——区间要么过窄（失覆盖）、要么被保角校准统一撑宽（过覆盖 + 高 ECE），**二者都让区间失去"按可信度排序靶点"的能力**，湿实验优先序失真；
- 根因定位：缺失**后验多样性（posterior diversity）**。常规模型/集成在 OOD 区"共识塌缩"——各成员预测收敛到同一点，集成方差无法反映真实的 posterior 散布。

PC-3 的判据（四条须同时成立才算"修复成功"）：

1. **H1** σ 与 τ（到训练流形距离）单调正相关；
2. **H2** ID 区间覆盖 ≈ 标称水平（如 0.95）；
3. **H3** OOD 区间相对 ID **变宽**（σ_ood / σ_id ≫ 1）；
4. **H4** 校准误差 ECE ≪ 0.08。

### 1.3 为什么 AI 可以介入、现有方案缺口

- 现有"拟合式"虚拟细胞模型（含朴素深度集成）能逼近 ID 响应，但**没有为 OOD 提供可信不确定度**，无法支撑赛题要求的"外推与泛化"判据；
- 保角校准（Conformal Prediction）只保证**边际覆盖**，其单一全局校正系数 q 无法让区间**随流形距离局部自适应**——这正是 PC-3 在基准上表现为"过覆盖 + 高 ECE"的机制；
- 因此缺口不是数据或算力，而是**一项机制设计**：如何让 epistemic σ 在 OOD 区正确放大。本方案用**proper-Bayesian 后验多样性**回答该问题，并用一组受控消融面板（§三）排除更廉价的替代机制。

## 二、技术方案与预期方法路线（技术路线概述）

### 2.1 总体技术路线

```
        组合扰动数据 (pa, pb, act, 主体 g, [神经调质])
                         │
        ┌────────────────┴─────────────────┐
   ① 组合孪生 Compositional Twin      do-演算层（相关 → 可证伪预测）
      (异速缩放响应 + 组合扰动编码)            │
                         │
        ② 保角校准 Conformal Calibration ──► 频率学覆盖保证 (nominal 0.95)
                         │                      但仅边际覆盖（单 q）
                         │
        ③ proper-Bayesian 后验多样性 ◄── 关键创新：让 σ 随流形距离局部自适应
           ├─ 可扩展路径：预条件/vanilla SGLD（多链+ burn-in + thinning + 裁剪）
           └─ 神谕验证：PyMC NUTS（小样本分层子集，确认是"后验"而非噪声）
                         │
        ④ OOD 分层评测（未见动作/未见主体/新调质）→ PC-3 四判据
                         │
        ⑤ 湿实验闭环：光遗传 / 钙成像 验证机制泛化
```

### 2.2 模块说明

**(1) 组合孪生 Compositional Twin。** 以组合扰动（单 / 双 / 三扰动）为输入，预测异速缩放（allometric）响应；用组合结构编码保证"未见组合"可被内插而非外推猜测。作为 ID 点估计与基准对照臂（P1 臂）。

**(2) 保角校准 Conformal Calibration。** 在 ID 校准集上估分位数 q，使区间满足理论边际覆盖。它是**可信度底座**（保证"不失覆盖"），但本方案明确指出其局限——单 q 无法局部自适应，必须配合 (3) 才能修复 PC-3。

**(3) proper-Bayesian 后验多样性（核心创新）。** 用真实后验采样（而非单次 MAP 或朴素集成）产生 epistemic σ：
- **可扩展路径**：SGLD 多链采样（vanilla / 轻量预条件），带 burn-in、thinning、梯度裁剪、权重衰减，提供恢复力约束随机游走；噪声尺度 ∝ √(2·lr·T)，多样性来自后验梯度噪声（**内禀**，不经 (f_m−f̄) 自举，故不依赖共识）；
- **神谕验证路径**：PyMC NUTS 在分层小样本子集上取得*proper* 后验，用于确认"是后验多样性、而非 Langevin 噪声本身"在修复 PC-3；
- 该机制直接把 σ 与后验散布绑定，使 σ 随流形距离单调放大（H1），区间在 OOD 自适应变宽（H3）。

**(4) OOD 分层评测。** 强制三组未见子集：未见**动作**（新化合物）、未见**主体**（新菌株）、新**神经调质**；逐子集报告覆盖@0.95、ECE、σ_epi 与 (σ, τ) 单调相关系数，作为 PC-3 判据的直接证据。

**(5) do-演算闭环。** 以 do-演算把"相关"升级为"可证伪预测"，并用光遗传 / 钙成像湿实验验证机制泛化，闭合赛题"AI 预测 → 湿实验验证"链路。

### 2.3 方法创新性（对应评审 20%）

- 把"OOD 不确定度可信度"问题**机制化**为 PC-3（epistemic under-scaling），并给出可证伪的四判据；
- 用**一组受控消融面板**区分三类候选机制（内禀后验 / 密度注入 / 密度门控），诚实排除两类、锁定一类——这是方法学贡献，而非单模型堆叠；
- 可扩展 SGLD 路径与 NUTS 神谕路径**双叉验证**，把"proper 后验"从黑箱假设变为可检验结论。

## 三、初步实验与可行性验证（核心证据）

> 本方案已在一个**组合扰动响应基准**（99k×217，含 pa/pb/act/主体 g/调质特征；结构化等价于方向一"未见化合物 / 未见菌株 / 组合"设定）上完成受控验证。该基准是方向一酵母蛋白质组任务的**组合扰动代理**，方法对数据集无假设，复赛可直接迁移至官方酵母扰动蛋白质组数据。

### 3.1 基准复现（P1 臂，GATE_REPRO 逐位验证）

标准组合孪生 + 保角校准作为对照臂，复现基准（GATE_REPRO=True，四子集 RMSE 逐位一致）：

| 子集 | 覆盖@0.95 | ECE | RMSE |
|---|---|---|---|
| id | 0.994 | 0.175 | 0.567 |
| ood_agent（未见主体） | 0.972 | 0.136 | 0.585 |
| ood_action（未见动作） | 0.999 | **0.206** | 0.635 |
| ood_neuro（新调质） | 0.992 | 0.170 | 0.603 |

**读出**：边际覆盖达标（甚至过覆盖），但 **ECE 高达 0.13–0.21**——正是 PC-3 的表征：单 q 保角校准无法让区间随 OOD 误差局部自适应，校准失效最严重发生在 ood_action（ECE 0.206）。

### 3.2 P5 三机制系统消融面板（诚实阴性，锁定正确方向）

为回答"用什么机制让 σ 在 OOD 放大"，我们并行测试三类候选，全部受控对照（同基准、同 GATE_REPRO、同 PC-3 判据）：

| 机制 | 设计 | 结果 | 死因 |
|---|---|---|---|
| **P5-B · 密度注入**（NCL + sample_weight） | 把训练密度注入损失去相关项 | **双阴性** | 集成共识塌缩：去相关项 ∝(f_m−f̄) 随成员 MSE 收敛→0，无法自举多样性 |
| **P5-A · SGLD 内禀后验** | 每成员独立后验链 | 覆盖结构性可修但**精炼阴性** | numpy-only 粗糙 SGLD 采样差：ECE 不越 0.08（下限≈0.094），点估计 RMSE 劣化 2.4–6×，集成均值塌缩（var_ratio≈1e-27） |
| **P5-C · GMM 密度门控** | σ = σ_id·h(1/q(x))，q=GaussianMixture | **阴性** | 217 维稀疏密度塌缩为二值新颖度（gate_ratio 全 1.0，density u 饱和 1.4e9），保角重标定把门控压平 |

**结论**：三类"测试时密度"类机制在真实基准上**全失败**；唯一显示结构性进展的是 P5-A 的**内禀后验多样性**（把覆盖送入有效带），但其 numpy-only 实现采样质量不足。这把"正确机制"精确锁定为 **proper-Bayesian 后验多样性**，并定位瓶颈在实现（工具链），而非方向。

### 3.3 P5-A2 · proper-Bayesian 重实现 spike（双叉验证：H1 单调性成立，σ 尺度待标定）

经授权进行工具链升级（torch 2.13 + PyMC 6.3），重实现 proper-Bayesian 孪生，在合成组合扰动数据（含 ID 紧流形 / OOD 远移四 stratum）上验证 PC-3 四判据：

**torch-SGLD 可扩展路径：**

| stratum | 覆盖@0.95 | ECE | 单调(σ,τ) | σ_epi | ood/id σ |
|---|---|---|---|---|---|
| id | 0.947 | 0.032 | +0.657 | 1.00 | 1.0× |
| ood_action | 1.000 | 0.050 | +0.803 | 3.71 | 3.7× |
| ood_agent | 1.000 | 0.050 | +0.579 | 4.33 | 4.3× |
| ood_neuro | 0.988 | 0.038 | +0.765 | 1.31 | 1.3× |

**PyMC-NUTS 神谕路径（确认是"后验"而非噪声）：**

| stratum | 覆盖@0.95 | ECE | 单调(σ,τ) | σ_epi | ood/id σ |
|---|---|---|---|---|---|
| id | 0.967 | 0.017 | +0.651 | 0.27 | 1.0× |
| ood_action | 0.998 | 0.048 | +0.869 | 8.14 | **8.1×** |
| ood_agent | 1.000 | 0.050 | +0.883 | 11.37 | **11.4×** |
| ood_neuro | 0.883 | 0.086 | +0.866 | 1.10 | 1.0× |

**读出（诚实重裁，按预锁判据 `ood_action 覆盖@0.95∈[0.93,0.97] 且 ECE<0.08`）**：

- **H1（σ 随流形距离单调）全 stratum 为正（+0.58~+0.88）→ 成立**，且是 PC-3 要害：numpy-SGLD 在此处失败（∂σ/∂τ≈0），proper-Bayesian 在此处成功（∂σ/∂τ>0 由后验构造满足）。这是本方案唯一站得住的**结构性正向信号**。
- **但覆盖越带**：`ood_action` 覆盖饱和（torch 1.0000 / PyMC 0.9975）、`ood_agent` 1.0000，均越预锁带上界 0.97；`ood_neuro` 反欠覆盖（PyMC 0.883）。→ 预锁判据第一合取项在两个方法上均失败。
- **ECE=0.02~0.05 是单档饱和地板，非校准成绩**：脚本 `ece()` 仅评单一名义档 0.95；当区间完全饱和（覆盖≡1.0）时 `ECE_单档 = |1−0.95| = 0.05` 是数学地板；canonical 4 档口径（0.5/0.8/0.9/0.95）饱和地板达 ≈0.21，远高于 0.08。故**单档 ECE 判据作废**，此后须声明档位口径。
- **结论（判据漂移警示）**：08-15 记录的「四假说全过」经预锁判据重裁为 **`P5A2_SYNTH_ACCEPTED = false`**。问题性质从「σ 不随新颖度变化」（numpy-SGLD 结构缺陷）精确降级为「**σ 随新颖度正确变化、但整体尺度过大**」（P5-A2 尺度标定问题）——后者可修、前者致命。P5-A2 从「已验证收口路径」降级为「**尺度未标定的候选路径，且仅有合成数据证据**」；R4 kill-switch 随之恢复生效。

### 3.4 关键科学发现

> **修复 PC-3 的正确机制方向 = 真实后验多样性（让 σ 的*排序*随流形距离上升），而非测试时密度门控。** 三机制消融把"密度注入 / 密度门控"两类廉价方案证伪；proper-Bayesian 双叉 spike 确认 **H1 单调性成立**（∂σ/∂τ>0），且 *proper 后验（NUTS）* 比 *Langevin 近似（SGLD）* 捕获更多 epistemic 散布（σ_ood/id 8–11× vs 3.7–4.3×）。**尚待解的子问题 = σ 尺度标定**：当前 σ 排序正确、但绝对尺度过大致覆盖饱和，须在校准层（多档 conformal / σ 重标定）收口后才能满足预锁判据。这条"诚实阴性 + 精确锁定 + 自审判据漂移"的证据链，正是本方案方法创新性的实证基础，也是评审最应采信的部分——它表明团队能识别并纠正自身过宣称，而非只报好消息。
