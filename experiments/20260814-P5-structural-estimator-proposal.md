## 0. 动机与问题陈述

PC-3（区间要宽保覆盖 / 要窄保可证伪）在 `compositional_twin` 上**四条独立路径全阴性**：

| 路径 | 机制 | 结果 |
|---|---|---|
| P4-1 | 校准层 localized conformal（改 q） | 四子集 q 退化回全局（ID 校准不覆盖 OOD） |
| 路A-empirical | novelty 门控 σ | 新颖度在离散特征空间本质是 0/1 二值 → 门控退化为开关 |
| 路A-heteroscedastic | σ_epi 门控 | ood_agent ECE 0.14→0.07，但判据目标 ood_action 仍饱和（cov 0.997 > 0.97） |
| P3-1b | virtual_twin 共形 | 仅 virtual_twin 修复（ECE 0.71→0.14），非 PC-3 判据目标 |

**根因（closure §3 三铁证）**：ID 的 `|resid|/σ` 分布与 OOD 子集系统性不同，且**无任何测试时协变量可预测该差**（novelty 常量/NaN；σ_epi 仅弱负相关且方向反）。这是 conformal i.i.d. 约束在本基准被打破的纯形式。

→ **测试时重标定（改 q 或乘门控 g）整体不可行**。唯一出路 = 改**结构性估计器**，让 σ(x) 在 OOD 上"天然正确"，而非事后修补。

## 1. Einstein 视角 · 被破坏的对称性与最小修复

**思想实验**：假设我们拥有无限 OOD 标注数据，重新训练 epistemic 估计器。它会学到什么？—— 在训练支撑稀疏处，集成*应当分散*（各成员外推方向不同 → 高方差）；在训练密集处，集成*应当收敛*。当前深度集成恰恰相反：所有成员在 ID 上训练出同一条函数，OOD 处外推*完全同步* → 方差塌缩 → σ 欠缩放。

**被破坏的对称性**：σ(x) 应关于"到训练流形距离" τ(x) **单调**——`∂σ/∂τ > 0`。现实：OOD 区 `∂σ/∂τ ≈ 0`（方差不随新颖度变化）。估计器对"点在训练密集区"与"点在 OOD 真空区"一视同仁。

**简化假设（Occam）**：不要事后乘 `g(·)`（路A 已证此路不通——因为 g 的回归量要么二值、要么反号）。最小修复 = 在**构造期**把缺失的多样性注入估计器，使 σ(x) 在模型自身后验/密度下天然正确。**修假设，不补输出。**

**理论审美**：proper-Bayesian 深度集成（后验在低数据区天然变宽）满足自然性 + 简洁性 + 统一性，是本问题最"美"的候选；密度感知注入是它在工程上的最小近似。

## 2. TRIZ 视角 · 物理矛盾 → 分离原理 → 发明原理

> 注：本提案应用 TRIZ **方法论**（矛盾→分离原理→发明原理）于 PC-3。若需 PatSnap 正式专利检索式创新，可另发 `run_triz_innovation_task`（须先脱敏内部研究，见技能隐私声明）。

**PC-3 物理矛盾**：同一参数（OOD 区间半宽 σ）同时要求 **宽**（覆盖@0.95 → [0.93,0.97]）与 **窄**（ECE < 0.08 即可证伪）。改善一方必损另一方。

**矛盾矩阵（改善测量可靠性/精度 ↔ 损失信息量/可控性）** → 推荐发明原理：#1 分割、#15 动态化、#28 机制替代、#35 参数变化。

**分离原理应用**：
- **空间分离（#1 分割）**：ID 区与 OOD 区用不同 σ 行为——但必须**连续**（路A 的二值 novelty 开关即失败于此）。
- **条件分离（#35 参数变化）**：改变 σ *度量*——从"同训练集成方差"（OOD 塌缩）换为"proper 后验预测方差"（OOD 扩张）。
- **机制替代（#28）**：用生成式 / 贝叶斯模型替代统计集成。
- **动态化（#15）**：σ 成为局部训练密度的*函数*（自适应），而非固定标量。

**综合解 = #28（贝叶斯替代）+ #15（密度自适应）+ #1（按密度空间分割）** → 落地为 §4 三机制。

## 4. P5 三机制候选

### P5-A · Proper-Bayesian 深度集成（TRIZ #28 + #15；Einstein 自然性）
- **机制**：以 SGLD / 循环-SGLD 在后验上采样权重，或用温度化似然 `p(y|x,w)^(1/T)`（大 T → 低数据区后验保持宽）。MC-dropout-as-Bayesian 为廉价近似（但常欠多样）。
- **为何治本**：后验在低数据区天然多样 → `∂σ/∂τ > 0` 由构造满足。
- **风险/成本**：SGLD 多轮 epoch、贵；先验选择敏感；若函数类无法表达 OOD 行为仍可能欠多样。
- **最小 spike**：在 1 隐藏层 MLP 上对 ood_action 跑 SGLD（20 链），比 P1 的 σ。

### P5-B · 密度感知多样性注入（TRIZ #1 + #15；Einstein 最小近似）
- **机制**：保留集成，训练期加正则 `R = Σ_m D(f_m(x), f̄(x)) · τ(x)`，τ(x)=训练特征 kNN *连续*密度（**非**路A 二值 novelty）。在训练支撑薄处*强制成员分散*，直接注入缺失 OOD 多样性。
- **为何优于路A**：连续密度 → 无二值开关塌缩；多样性在构造期注入，非测试时乘标量。
- **风险**：正则权重错配会伤 ID 精度；须保 linear 点估计不动。
- **最小 spike**：在现有 `compositional_twin` 集成上加 τ(x) 加权分散正则，扫 λ∈{0.01,0.05,0.1}。

### P5-C · 生成式 epistemic（TRIZ #28 + #35；Einstein 解耦）
- **机制**：先拟合训练特征密度模型 q(x)（flow/GMM/VAE），定义 `σ(x) = σ_id(x) · h(1/q(x))`，h *学习*单调（非阈值）。把"数据在哪"（生成）与"函数是什么"（集成）*解耦*——OOD 撑大由密度 principled、平滑给出。
- **为何治本**：路A 的 kNN novelty 失败在二值；生成密度 q(x) 连续可微，天然给平滑梯度。
- **风险**：密度模型质量；对抗区 q(x) 可能误校。
- **最小 spike**：GMM/MAF 拟 Norman 特征，h 用 1 层单调网络，看 ood_action ECE。
