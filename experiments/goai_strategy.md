## 1. 赛制关键事实（来自 FAQ + PDF）
- 赛道定位：**前沿探索（AI for Research）** = GOAI Track 3 "AI for Science"。不只看单点模型效果，看"把科学问题转化为可计算/可验证/可复现的探索任务，形成 问题定义→环境设计→算法运行→研究信号解释 的完整闭环"。
- **两条参赛路径**：
  - 算法赛题：明确评测方式，基于组委会数据集建模（首批含 **虚拟细胞、小分子-蛋白质结合轨迹预测、材料科学文献智能体**）。
  - 开放探索赛题：自定义问题/探索环境/发现信号，鼓励 Agent 可持续探索闭环。
- **虚拟细胞（虚拟酵母扰动响应预测）= 算法赛题方向之一** —— 正是本项目 `goai_virtualcell_adapter.py` 的目标。
- **数据集当前非公开、但将下发**：FAQ Q9/Q10 明确"虚拟细胞数据集目前为非公开状态，数据授权协议仍在签署中，组委会将协议完成后通知已报名选手"。→ 当前无法获取，但后续会下发（用户已确认）。**关键不确定项 = 下发时间 vs 赛段截止（初赛 8.16 / 复赛 9.3）**。
- **评审五维度**（FAQ Q7）：① 问题定义与科学价值 ② 探索环境/评测框架设计 ③ 可运行性·可复现性·证据质量 ④ 探索过程与研究信号 ⑤ 开放贡献与长期研究潜力。
- **虚拟细胞想要 self-evolving / active learning**（FAQ Q12）：希望模型能判断哪些实验条件更有价值、主动指导数据采集 —— 即"由模型决定需要什么数据并推动自身能力提升"。

## 3. 当前获奖希望（诚实诊断）

### 3.1 数据下发前的现状
- **算法赛题 / 虚拟细胞：当前无法参赛（外部阻断）。** 数据集未下发，连训练数据都拿不到，无法产出"在真实数据上可运行、可复现的算法方案"——这是时机问题，不是能力问题。
- **开放探索赛题：有真实可讲的故事，但需重构交付物。** 该路径**不要求组委会数据集**（FAQ Q9：唯一例外是虚拟细胞）。我们可完全基于公开/合成数据 + 自研探索环境参赛，已具备：可运行仿真环境、诚实 OOD 评估框架、闭环自学习设计、负结果研究信号。

### 3.2 数据下发后的情景重估（用户已确认"后面会发"）
数据下发**移除外部阻断**，虚拟细胞算法赛题变为可参赛。但"拿得到数据"≠"能赢"。获奖希望取决于三个仍未知的量，分三种情景：

| 情景 | 数据性质 | 我们的优势能否发挥 | 赢面 |
|---|---|---|---|
| A. 纯精度 leaderboard + 富 epistasis | 扰动级双线性主导（类似我们合成代理 ε 大） | 黑箱 MLP/GEARS 类占优；P1/P2 仅 ≈ 线性（已证） | **低（~10–15%）** |
| B. 含 OOD 组合泛化评测 + 加法/可分解结构 | held-out 化合物对、响应可分解 | 我们的 OOD 评估框架 + 结构化先验正对路；黑箱外推易崩 | **中（~35–50%）** |
| C. 评测重"方法/范式/自进化"而非纯 RMSE | 看探索过程、active-learning、可复现 | 我们的范式创造奖候选 + Phase D self-evolving 直接命中（Q12） | **中高（~40–55%）** |

**内部硬约束（不随数据下发改变）**：我们自己的 epistasis 合成代理扫描已证明 —— 在富 epistasis 数据上，P2 交互头**不敌黑箱 MLP**，结构化先验仅在纯加法 regime 占优。因此"在真实数据上靠组合先验击败黑箱拿精度冠军"这一路径，即便数据下发也**概率很低**（情景 A）。希望在于**错位竞争**：把比赛打成"方法/范式/OOD 泛化/自进化"的较量（情景 B+C），而非纯精度军备竞赛。

**新增风险：下发时间。** 若数据在初赛 8.16 后才下发 → 算法赛题只能从复赛介入，初赛阶段仍需以开放探索赛题保底。若数据在 8.16 前下发 → 双线并行，但 15 天内要同时搭好 dual-compound 适配器 + 跑真实基准 + 写 4 页文档，资源极紧。

### 3.3 数据下发后的必做动作（把"下发"变成"机会"）
1. **立即扩展 `goai_virtualcell_adapter.py`** 从单化合物草稿 → 支持双化合物组合行（这是当前 TODO）；
2. **在真实 GOAI 数据上重跑 P1/P2/基线 OOD 基准** —— 这正是我们之前用合成代理回答、现可得到**真实答案**的问题："交互头在更富 epistasis 的真实数据上能否拉开差距"；
3. **按真实数据结果定姿态**：若 GOAI 落在情景 B（有可分解/OOD 结构）→ 主打结构化先验 + OOD 评估框架；若落在情景 A（富 epistasis）→ 放弃精度叙事，转 C 路线（范式/自进化/诚实负结果）或开放探索赛题。

## 4. DIO（系统化问题解决）提高获奖概率的方案
### 4.1 诊断域（差距分析：我们 vs 评审五维度）

| ②探索环境/评测框架 | OOD 双栏 + 校准（范式创造奖候选） | 需包装成"动态科学评测框架"并演示 |

### 4.2 TRIZ 突破域（矛盾破解）
- **技术矛盾**：改善"真实数据驱动的科学发现价值" ↔ 恶化"拿不到虚拟细胞数据（无法参赛）"。
  - 矛盾矩阵推荐方向：#24 中介物（插入仿真/合成数据层作介质）、#10 预操作（先建探索环境）、#35 参数变化 / #17 维度变化（从"预测真实响应"重构为"自进化探索环境"）。
  - **分离原理（条件分离）**：算法赛题需真实数据 → 我们条件不满足；开放探索赛题不需 → 切换赛道，绕过硬阻断。
- **物理矛盾**：既要"靠真实湿实验证据"（科学可信）又要"现在就拿不到数据"。→ **时间分离**：现在用合成仿真环境作"虚拟湿实验"，把闭环跑通并证明自进化能力；真数据可用时即插即用。

## 5. 结论
- **数据下发会移除"虚拟细胞算法赛题"的外部阻断，但能否赢取决于数据性质与评测口径，不取决于"拿没拿到数据"。**
- **纯精度军备竞赛（情景 A）：即便数据下发也概率很低（~10–15%）** —— 我们自己的 epistasis 扫描已证明结构化先验在富 epistasis 上不敌黑箱，这是方法学事实，不因真实数据而逆转。
- **真正的希望在于错位竞争（情景 B+C，~35–55%）**：把比赛打成 OOD 组合泛化 / 方法范式 / self-evolving 的较量。我们的 OOD 评估框架（范式创造奖候选）、Phase D 闭环自学习（命中 Q12）、诚实负结果信号，都是官方明确奖励、且黑箱选手不一定有的差异化资产。
- **一句话**：数据下发 ≠ 自动有希望；有希望的前提是（a）下发时间早到能搭建提交，（b）我们主动把叙事从"精度"转向"范式/机制/OOD/自进化"。方向建议仍是"开放探索赛题保底 + 虚拟细胞作可插拔数据接口"，数据下发后按 3.3 三步把机会变现。

## 5.5 虚拟细胞解题思路研究（2026-08-04，Datawhale 官方 49 页教程）

- **教程提分主架构 = 残差分解（共享+化合物特异+菌株调制+交互项），即我们的 CompositionalTwin**——但教程没写交互项怎么设计；我们的 P1/P2/epistasis 扫描/MISATO 实证给出了答案：**纯加法分解不赢、必须做不依赖实体身份查表的对称交互头 ψ（依赖基因组/SMILES 表征），且不要押注"加法先验击败黑箱"**。
- **评测 6 模块 65% 围绕 Δ=处理−对照**（FC 25%+两个残差 40%）→ 模型应直接以 Δ 为监督目标（适配器已默认 target=Δ）。
- **验证场景 val_chem_only/val_strain_only/val_both(269 样本)= 本项目 ood_action/ood_agent/ood_combo**——教程强制分场景报告 = 我们的记忆vs机制双栏，且我们带 bootstrap CI + 校准（评审证据质量）。

- **新风险：模板同质化**（官方教程 = 大量选手同模板）→ 差异化必须靠实证故事（跨域 OOD 结论、消融量化、外部数据虚拟实验）而非架构名。
- **待决策：算法赛（虚拟细胞）vs 开放探索（BridgeMD 已交 v2）二选一**；数据 8/5 下发后 ~11 天到初赛截止，动作清单见研究文档 §6。

## 6. 两手准备：Hand 1 虚拟细胞 + Hand 2 结合轨迹（MISATO）

### 6.1 MISATO 有用吗？——战略上强烈有用，工程上受沙箱限制
- **领域精准**：MISATO = "structure-based drug discovery" MD 数据集，正是 FAQ 算法赛题"小分子-蛋白质结合轨迹预测"方向；且**公开**，现在就能动手，不赌组委会下发。规模 train 13,066 / val+test 1,357 复合物轨迹（来自 train_MD/val_MD/test_MD.txt）。
- **体量实测**（Zenodo record 7711953，2023-05-24）：`MD.hdf5` **132.84 GB**、parameter_restart 54 GB、densities 5.7 GB、`QM.hdf5` **0.34 GB**、切分文件 <1 MB；全量 193 GB。
- **工程约束（沙箱）**：133 GB MD 主体在托管环境拉不动（出口对 ≥1MB 持续传输掐断 + 存储/时长），需用户**本机下好丢入工作区**；或先只用 0.34 GB `QM.hdf5` + 切分文件搭骨架。
- **能力约束（modality gap）**：我们的代码是扰动响应（omics）专用；MISATO 是 MD 轨迹（3D 坐标）→ 需新建适配器 + 大概率 GNN/等变模型头。可转移的是"记忆 vs 机制 / OOD 子集 / 校准"评估框架思想，实现从零搭。

### 6.3 MISATO 落地路径（受沙箱限制下的可行动作）
1. **✅ 立即（不需大数据，已完成骨架）**：下 train/val/test_MD.txt（<1 MB，落 `data/raw/misato/`）→ 校验切分干净（train 13,765 / val 1,595 / test 1,612，全唯一零重叠）→ 建 `code/data/misato_ood_splits.py`（RCSB GraphQL 取配体`nonpolymer_comp_id`+蛋白`uniprot_ids`/`macromolecular_names`，带缓存）→ 定义 **LLO（held-out 配体）/ LPO（held-out 蛋白）/ COMBO（held-out 配体×蛋白对）** 三轴 OOD 切分。样本 200 校验：配体-OOD 49 / 蛋白-OOD 80 / 组合-OOD 108 → **证明"记忆 vs 机制"框架可迁移到结合轨迹域（中介物策略，不需 133 GB）**。全量 16,972 抓取已完成 → `data/processed/misato_ood_splits.json` + `misato_rcsb_cache.json`（16,961 复合物元数据）。
2. **✅ QM.hdf5 已跑通（用户确认 option 1，2026-08-01）**：MD.hdf5(133GB) 本机下太慢，转 QM.hdf5(340MB) 轻量路径。实测 Zenodo 可达（不被 bulk 掐断），用户本机下完并覆盖我下崩的残缺文件 → 已就位 `data/raw/misato/QM.hdf5`。装 h5py 3.16（pip 恢复）。建 `code/benchmark_misato.py`：镜像 omics P1/P2/MLP 对照——扰动=(配体,蛋白)对、模型=加性 Ridge(=P1) vs 黑箱 MLP(=P2 想打败对象) vs KNN/均值、评测=id/配体-OOD/蛋白-OOD/组合-OOD + bootstrap 95% CI。**关键实测修正**：QM.hdf5 实际 schema 是每复合物 `mol_properties/` 下 7 个**配体分子级 QM 标量**（Ionization_Potential 等），**不含结合能**（结合能在 MD.hdf5）→ 自动选 `Ionization_Potential` 作目标。结果（usable 16,046）：OOD **不退化**（combo_ood ridge 0.877 ≈ id_test 0.903，与 omics epistasis 扫描相反，因目标与 protein 无关、不构成真组合 OOD）；加性 ridge 退化到均值(0.88)；MLP 的 0.68 优势是目标分布匹配非真泛化。→ 这是**框架验证 + 诚实负结果**（对应评审维度④），**不能回答结合能科学问题**；真竞争力需 MD.hdf5 结合能目标 + RDKit 特征。产物：`experiments/misato_ood_benchmark.{json,md}`。
3. **全轨迹模型**：待用户本机下好 MD.hdf5 丢入工作区（或 GOAI 真实结合数据下发）→ 建 MD 适配器 + GNN/等变头 → 上全量。
