## 5. 不确定度说明

- RMSE 经 100 次 bootstrap 给出 95% 置信区间；覆盖度/ECE 衡量预测区间是否可靠。
- 虚拟孪生不确定度 = 集成 epistemic + 新颖度(OOD) 合成；在未见条件下新颖度会撑宽区间，缓解黑箱同方差不确定度的过度自信。
- 所有 OOD 结论均带 CI；若 CI 重叠则视为「不显著」，避免过拟合式误判。

## 6. 子集定义（OOD 语义，诚实标注）

- **ID(已见基因)**：已见单扰动基因、已见批次的 held-out 细胞（in-distribution，与训练同分布）。
- **OOD-未见基因(ood_agent)**：20% 单扰动基因从未在训练出现——真正未见扰动身份 → **标注为「不强制外推」**（如实报告，不要求外推）。
- **OOD-组合双扰动(ood_action)**：双扰动中 held-out *基因对*（两基因均见过单扰动、但该具体组合从未训练）——**真正的机制组合泛化检验**（须组合两条已见单扰动效应）；标注为「应外推」。训练集已含部分双扰动（可学 epistasis）。
- **OOD-未见批次(ood_neuro)**：gemgroup=8 批次从未在训练出现——混杂因子 OOD → **标注为「不强制外推」**。

### A.2 关键判读（两处**不同方向**的失校准）

1. **饱和退化（ood_agent / ood_action）**：三个孪生的覆盖度在全部 4 个名义水平上**恒为 1.000**，
   即区间宽度与名义置信水平**完全脱耦**。此时 ECE 恒等于 `mean(|1−level|) = (0.50+0.20+0.10+0.05)/4 = 0.2125`，
   与实测 0.212 逐位吻合 → **可确证这是数值饱和，而非「保守但可用」**。
   机制：VirtualTwin 的 novelty(OOD 新颖度) 项被加进 sigma；在未见条件下 novelty 爆炸 → sigma → 很大 → 区间吞掉全部残差。
   后果：孪生在 OOD 上**报不出可用的不确定度**，"区间宽 = 诚实" 的说法在这里不成立（无分辨力的区间不携带信息）。

2. **灾难性过度自信（ID / ood_neuro，仅 virtual_twin）**：未经 conformal 包裹的原始集成方差把区间压窄约一个数量级
   （名义 50% 实覆 3.2%）。这是**尚未根因闭环的活跃缺陷**，与已闭环的 epistasis 叙事无关。
   对照：P2 交互项孪生（conformal 生效）在同子集 ECE 0.057–0.067，说明缺陷定位在**未走 conformal 的路径**，而非模型本身。

### A.3 对第 3 节判据的效力限定（诚实边界）

- ood_action 的「疑似仅记忆」判据（Δ = −0.0089 / −0.0053）**仅基于点估计 RMSE**；
  由于该子集上孪生的区间退化，本周**无法**用区间/校准指标交叉验证该判据。
- 因此本判据的正确表述是：**「在点估计层面未显著优于线性基线」**，而非「已证明模型只在记忆」。
- 反向亦成立：线性/MLP 在 OOD 上 ECE 0.013–0.027、覆盖度单调合理，**基线的不确定度反而是当前唯一可信的**。

### B.2 TRIZ 矛盾分类与破法

**矛盾 1（物理矛盾 · 本周主攻）：OOD 不确定度既要变宽又不能饱和**
- 表述：在未见条件下区间必须变宽以诚实反映未知；但一旦宽到覆盖恒为 1，就失去随置信水平伸缩的分辨力，不确定度变成无信息量。同一物理量被要求同时「大」与「不大」。
- 破法 = **条件分离 + 空间分离**：把当前混在一起的 sigma 拆成两路分别输出，互不污染
  - `sigma_pred`：只由 conformal 分位数标定，**必须随名义水平单调伸缩**（负责区间）。
  - `novelty_score`：作为**独立的 OOD 分数**单独报告，**不再加进区间宽度**（负责「要不要相信这个预测 / 是否升级为湿实验」）。
- 破法 = **时间分离**：novelty 只在**决策阶段**（拒绝预测 / 触发光遗传·钙成像验证）生效，不在**估计阶段**（构造区间）生效。
- 反模式警戒：禁止用「再加一层网络 / 再调一个温度系数」掩盖——这是接口设计缺陷，不是容量缺陷。

**矛盾 2（流程矛盾 · 元层面）：周度基准既要冻结又要产新证据**
- 事实：本周产物与 20260802 / 20260805 报告**逐字节一致**（仅时间戳不同，已 diff 验证）。seed=0 + 数据冻结 + 模型冻结 ⇒ 周度重跑的信息增量为 0，却消耗 13m46s 全量算力。
- 破法 = **条件分离**：拆成两条腿
  - (a) **确定性回归守卫**：对 `results` 段做哈希比对，秒级完成，任何数值漂移即告警（守住可复现性）。
  - (b) **每周轮转「新证据槽」**：每周换一个机制轴做增量诊断（本周槽 = 校准诊断，已产出 A.1–A.3）。
