# MISATO Hand-2 · MD 真结合能组合 OOD 基准

> 迁移虚拟镜像神经元 OOD 评测框架到小分子–蛋白结合域。
> 目标:检验「加性先验(P1 类比)在组合 OOD 上是否优于黑箱(MLP, P2 类比)」——omics 那条结论(加法先验仅纯加法 regime 占优、富 epistasis 时黑箱反超)是否在结合域重演。

## 1. 设置

| 项 | 值 |
|---|---|
| 数据源 | `data/raw/misato/MD.hdf5`(132.84 GB,16972 复合物组) |
| 目标 | `frames_interaction_energy`(逐复合物 100 帧 MM 相互作用能,取均值 → 1 标量/复合物) |
| 可用复合物 | 16047(有目标 + RCSB 配体/蛋白元数据 + 切分覆盖) |
| 特征 | **弱特征**:配体 ID + 蛋白 ID 的确定性 hash 向量(各 32 维,拼接 64 维)。**非** RDKit 语义描述符(留待用户本机升级)。 |
| 模型 | 加性 Ridge(=P1 加法先验) / 黑箱 MLP(=P2) / KNN / 全局均值 |
| OOD 三轴 | LLO(held-out 配体) / LPO(held-out 蛋白) / COMBO(held-out 配体×蛋白对) |
| 评测 | RMSE + bootstrap 95% CI(200 次);区分记忆(train/id)vs 机制(combo_ood) |

切分规模:`train=13198, id_val=1413, id_test=1436, ligand_ood=4953, protein_ood=6014, combo_ood=9116`。
(注意:OOD 子集与训练集**按 RCSB 配体/蛋白身份**互斥,是真实机制泛化切分。)

## 2. 结果(RMSE,带 95% CI)

| 子集 | 加性 ridge | 黑箱 MLP | KNN | 均值 |
|---|---|---|---|---|
| train | 36.15 [32.5,40.0] | 25.05 [23.1,27.3] | 27.06 [24.3,30.0] | 36.37 [32.7,40.3] |
| id_test | 70.91 [62.8,78.5] | 70.66 [63.5,77.7] | 67.89 [61.1,74.8] | 71.03 [62.9,78.6] |
| ligand_ood | 47.39 [41.6,54.4] | 42.75 [38.2,47.9] | 42.99 [38.0,49.0] | 47.52 [41.7,54.6] |
| protein_ood | 55.97 [50.3,61.9] | 47.62 [43.4,51.6] | 48.23 [43.5,52.9] | 56.10 [50.4,62.0] |
| **combo_ood** | **50.89 [46.7,55.5]** | **44.40 [40.9,48.4]** | **44.82 [41.4,48.5]** | **51.05 [46.8,55.7]** |

## 3. 解读(诚实版)

### 3.1 弱特征严重过拟合
train→id_test 从 ~36 暴涨到 ~71(Ridge/MLP 均如此),说明 hash ID 特征只能记忆训练集内复合物,无法外推——这是弱特征的预期行为,**绝对值无化学意义**。

### 3.2 "OOD RMSE < id_test" 是分布假象,不是泛化胜利
所有模型的 `combo_ood`(50–51)都**低于** `id_test`(~71)。这不是「OOD 不退化」。
`id_test` 是从全体复合物随机抽的,包含作用能更极端的样本;OOD 子集(held-out 配体/蛋白/组合)碰巧更接近全局均值。
→ **不能用 combo_ood/id_test 比值报「不退化」**,该比值(ridge 0.718)是误导性的。

### 3.3 真正的信号:加性先验在组合 OOD 上**崩塌为均值**,黑箱存活
关键对比(看 CI 是否重叠):
- **combo_ood**:加性 ridge **50.9 [46.7,55.5] ≈ 均值 51.0 [46.8,55.7]**(CI 几乎完全重合 → 加性先验**统计上等于平凡均值预测器**);而黑箱 MLP **44.4 [40.9,48.4]** 与 KNN **44.8** 显著低于均值(差值 ~6.5,CI 不重叠)。
- 该模式在 ligand_ood / protein_ood 同样成立(ridge≈mean,MLP/KNN 明显低于 mean)。
- 即便在 id_test,ridge 70.9 ≈ mean 71.0——**加性先验在所有子集上都不如均值预测器有区分度**,唯黑箱 MLP/KNN 稳定胜出。

**结论**:蛋白–配体相互作用能**不可**被「配体效应 + 蛋白效应」的加性分解刻画(P1 式加法先验失效、退化为均值);能捕捉非加性配体×蛋白耦合的黑箱(MLP/KNN)才保留预测力。这与 omics epistasis 扫描的**方向一致**——加法先验的价值是 regime 依赖的:目标可加性分解时有效(omics P1 与线性基线持平),目标含强非加性耦合(结合相互作用能)时崩塌。这正是 TRIZ 落到的「归纳偏置的 regime 依赖」矛盾。

## 4. 局限(必须声明)

1. **弱特征**:hash ID 而非 RDKit 语义描述符 + 蛋白 embedding。黑箱的「胜出」实质是「在 hash 邻域里取相似复合物均值」(MLP≈KNN 印证),**未验证真实化学结构**。要得到有化学意义的结论,须升级 RDKit 特征后重跑。
2. **目标是 MM 相互作用能代理**,非严格结合自由能(MM-GBSA 总分需额外组分聚合;此处 `frames_interaction_energy` 是直接可用的逐帧标量,作为结合相关量的代理)。
3. 未做校准/ECE(回归 RMSE 任务,非分类),SOP 校准轴未在此启用。

## 5. 对 GOAI 策略的意义

- Hand 2 现在在结合域有了一个**真实的**(虽弱特征)组合 OOD 结果:**加法先验在 held-out 配体×蛋白组合上退化为均值,黑箱存活**。它与 omics 结论形成跨域呼应——「组合泛化必须学非加性(epistasis)结构,而非仅靠加法先验」。
- 这支撑 GOAI「方法/范式」赛道角度:一个能区分「加法先验 vs 黑箱 on held-out 组合」的基准本身,就是可辩护的贡献。
- **升级路径**(用户本机):装 RDKit → 把 hash 特征换成配体语义描述符 + 蛋白 embedding → 重跑本脚本(`--qm-mode md`),得化学可解释结论。
