# P3-1 阶段报告：σ 解耦 + 有界门控（干掉 0.2125 饱和的进展）

> 日期：2026-08-07 | 模型：Norman scRNA（canonical 配置，seed=0 复用缓存）
> 验证脚本：`scripts/verify_p31.py` | 基线：`experiments/multiseed/aggregate_seed0.json`

## 1. 根因（W32 实测确认的 0.2125 饱和因果链）

`code/model/compositional.py` 与 `twin.py` 的 `predict` 把 `novelty_std` **平方加进 y_std**：
```
y_std = sqrt(y_std_epi² + novelty_std²)   # novelty_std = k·max(0, nd_rel-1)
```
OOD（nd_rel≫1）上 novelty 飙升 → 区间撑到无限宽 → coverage 锁 1.0 → ECE = mean(|1-level|) = **0.2125（饱和签名）**。
compositional 双孪生在 ood_agent/ood_action 上 coverage 恒 1.0、ECE=0.2125。

## 2. P3-1 已实施的代码改动

| 文件 | 改动 |
|---|---|
| `code/model/compositional.py` (CompositionalTwin + InteractionTwin `predict`) | ① 删除 novelty 平方加和（σ 解耦）；② 加 sigmoid 有界门控 `gate=1+k·σ(2·(nd_rel-1))∈[1,1+k]` 让 OOD 不确定度适度增大但封顶；③ 加 `_sigma_epi_quantile` + fit 记录 `sigma_id_95_` + predict 用 `cap=10×sigma_id_95_` 封顶 epistemic 爆炸；④ 返回 `(mean, sigma_pred, nd_rel)` 接口不变 |
| `code/model/twin.py` (VirtualTwin `predict`) | ① 同样 σ 解耦（novelty 不再进 y_std） |

下游 `benchmark_ood.py` 的 `predict_with_std`（conformal 模式返回 `self._q * std`）**无需改**，接口三元组不变。

## 3. 验证结果（seed=0，对比基线 0.2125）

**conformal=True（canonical 配置）**：

| 模型 | 子集 | cov95 before | cov95 after | ECE before | ECE after | 判定 |
|---|---|---|---|---|---|---|
| compositional_twin | ood_agent | 1.0 | **0.9483** | 0.2125 | **0.0887** | ✅ 饱和消除 |
| compositional_twin | ood_action | 1.0 | 0.9982 | 0.2125 | 0.1965 | ❌ 仍饱和 |
| compositional_interaction_twin | ood_agent | 1.0 | **0.8966** | 0.2125 | **0.0479** | ✅ 饱和消除 |
| compositional_interaction_twin | ood_action | 1.0 | 1.0 | 0.2125 | 0.2125 | ❌ 纹丝不动 |
| virtual_twin | ood_agent/ood_action | 1.0 | 0.07-0.11 | 0.2125 | 0.70+ | ❌ 过度自信（未开 conformal + epistemic 坍缩）|

**诊断关键点**：
- ood_agent 饱和**已彻底消除**（ECE 0.2125→0.05-0.09，cov 落在 0.90-0.95 合理区间）→ P3-1 解耦+门控对「未见菌株」有效。
- ood_action **仍饱和**。拆因：
  - raw σ_pred 经「门控+封顶」后已被压到 ~0.69（cap=10×ID95=0.687），但 **conformal `_q` 在 ID 上就过大**（compositional_twin `_q≈3.4`、interaction_twin `_q≈32`），把 OOD 区间又放大回饱和。
  - 关掉 conformal 测 raw σ_pred：ID coverage 直接掉到 0.15（过度自信）→ 证明 **conformal 单标量 `_q` 是必要的，但它假设 ID/OOD 归一化残差同分布，OOD 上被迫 ID 外推放大**。

## 4. 结论：0.2125 饱和「部分干掉」

- ✅ **ood_agent（未见菌株）的 0.2125 饱和已消除** —— P3-1 结构修复有效。
- ❌ **ood_action（held-out 基因对）的 0.2125 饱和仍在** —— 这是**本质性限制**，非 P3-1 能单独解：
  1. held-out 基因对只在测试集，无 OOD 校准数据 → conformal 单标量 `_q` 被迫用 ID 值外推；
  2. 该子集 epistemic 方差结构性爆炸（MLP ensemble OOD 病态），模型确实不知道这些组合响应。

## 5. 下一步（P3 完整架构，非 P3-1 范围）

干掉 ood_action 饱和需以下之一（均超出本次「σ 解耦」范围）：
1. **分 subset 共形（split conformal）**：用训练集中对应子集的样本标定各自 `_q`。但 ood_action 的 held-out 基因对在训练集为 0 → 需改造数据切分（P1 已隔离）→ 不可行，除非放宽 P1 隔离。
2. **PRESCRIBE（arXiv 2510.07964）深度证据回归**：epistemic/aleatoric 分离 + 有界不确定度，让 σ_pred 本身在 OOD 上有上界（非 conformal 外推）。
3. **ACC-CRL（arXiv 2607.02572）结构门控 `g(u)`**：用门控在加性/交互 regime 间切换，约束 epistemic 随新颖度饱和而非爆炸。
4. **virtual_twin 补 conformal + epistemic 随新颖度注入**：当前 virtual_twin 在 OOD 上过度自信（cov<0.12），需独立修复。
5. **Chreode 转移算子预训练（arXiv:2605.28111, 2026-05）**：跨尺度 / 跨情境预训练一步式 Waddington 残差算子（势能梯度 + 反对称流 + 随机扩散），作为 GEARS embedding 注入 Norman Perturb-seq 将 DE20 MSE 降 **12.4%**（0.2121→0.1858，已含 scVI 中性对照隔离时序贡献）。启示：孪生应先在共享潜几何上预训练转移算子、再把扰动作为 action-conditioned 残差叠加，而非从零学每个扰动——直接缓解 P2 epistasis 代理扫描中「结构化先验仅在纯加法 regime 占优、扰动级 epistasis 被黑箱 MLP 拉开」的瓶颈。属 P3 赛后深化（大工程），不阻塞 8/16。
