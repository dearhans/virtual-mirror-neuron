# P2 交互头在「更富 epistasis」合成数据上的差距扫描

**日期**：2026-08-01
**动机**：真实 GOAI 数据在本工作区不可用（适配层为单化合物草稿、数据未下发、沙箱无法拉取），
用户选择用**受控 epistasis 合成代理**直接回答科学问题——「交互头在更富 epistasis 的数据集上能否拉开差距」。

## 方法
- 扩展 `code/data/loaders.py::generate_compositional_dataset`，新增可调**交叉组件 epistasis** 项：
  - `kappa(a,b) = (a·w_int) * (b·w_int)`（交叉双线性，仅双扰动非零；单扰动 Pb=0→κ=0 不受影响）
  - `y = g·( z_single(a) + z_single(b) + ε·κ(a,b) )`，`ε` 即 epistasis 强度
  - `ε=0` 时与旧生成器行为完全一致（κ 项 ×0）
- 扫描 `ε ∈ {0.0, 0.3, 0.6, 1.0, 1.5, 2.0}`，每档 `n_train=2400, n_test=600, Dp=8, mag_train=0.6, mag_ood=1.4, noise=0.15`
- **严格复刻 benchmark_ood.run() 方法学**：仅在 `split=='train'`（单扰动 + 低幅度双扰动）上拟合，
  在 held-out `ood_action`（**大幅度双扰动外推**，mag 5× 外推）上评估 RMSE + bootstrap 95% CI
- 对比模型（同超参）：P2 交互头 / P1 加法先验 / MLP黑箱 / VirtualTwin / 线性 / KNN / 均值

## 结论（诚实、决定性）
1. **P2 交互头没有拉开差距**：在所有 ε 下 P2 ≈ P1（差值 <0.05，纯噪声），且 **P2 与线性基线几乎重合**
   （ε=1.0: 12.13 vs 12.24；ε=2.0: 24.44 vs 24.39）。交互头注入的 epistasis 残差未被有效利用。
2. **真正吃到 richer epistasis 的是黑箱 MLP**：随 ε 增大，MLP 相对结构化模型的优势单调扩大
   （ε=2.0: MLP 10.9 vs P2 24.4，差距 2.2×）。MLP 直接从原始 (pa,pb) 拟合并外推双线性。
3. **结构化先验仅在「纯加法」 regime 占优**：ε=0 时 P1/P2（~0.78）显著优于 MLP（1.69）/线性（3.31）；
   一旦响应含真实非加和结构（扰动级双线性），黑箱反超，结构化头退化为与线性同效。

## 机制解释
注入的 epistasis `κ=(a·w_int)(b·w_int)` 是**原始扰动级**的双线性。P2 的 ψ 作用在 **φ 效应特征**
`h=[e_a+e_b, e_a⊙e_b]` 上，而 φ 只被监督拟合加法机制 `z_single`（用投影 `w`，非 `w_int`），
故 h **不携带表达 κ 所需的信息**；且 ψ 须从低幅度(0.6)外推到高幅度(1.4)（×5）。
反观 MLP 直接见原始 pa,pb，可端到端拟合并外推双线性 → 信息占优。

## 对项目的含义（重要修正）
- **P2 交互头（效应级对称特征）无法捕获「扰动级 epistasis」**；若真实 epistasis 存在于扰动级，
  黑箱必胜，结构化先验毫无机制优势。
- 与真实 Norman 结果一致：P2 0.632 vs 基线 0.627（CI 重叠、持平）——真实 epistasis 信号要么小，
  要么处于结构化头无法利用的表示 regime。
- **核心结论收紧**：组合性/加法先验（P1）及其交互头扩展（P2）**只在响应确为加和时才是有效归纳偏置**；
  对非加和响应，要么需要 epistasis 显式表达在效应级（此时头或可帮），要么直接用灵活黑箱。
  「组合先验具机制优势」的宣称须进一步限定——它不构成对灵活黑箱的普遍胜势。
- **GOAI 真实数据**：仍待用户下发 `train_val.csv`（含双化合物组合行）或提供可达下载地址；
  届时扩展 `goai_virtualcell_adapter.py` 支持 dual-compound 解析后重跑即可，本扫描已给出预期判据
  （看 P2 是否显著低于 MLP/线性——预期若 GOAI epistasis 也是扰动级，则结论同上）。
