## 0. 假设与事前锁定的判据（W33 §7 P0）

**待检假设**：组合孪生 epistemic std 在 OOD 上一致欠缩放 ~41×（P4-1 阴性已将 PC-3 重定位为
epistemic 估计器缺陷，非校准层可修）。路 A = 让 std 自身随**新颖度**撑大，正面攻克该根因。
校准层 q 保持单标量（与 P4-1 划清：P4-1 改 q，路 A 改 σ 估计器）。

**判据（跑前冻结）**：ood_action 上**路 A** 的 覆盖@0.95 ∈ [0.93, 0.97] **且** ECE < 0.08。

## 1. 实现（两机制变体，同模型类）

`code/model/compositional_p4a.py`：`NoveltyGatedCompositionalTwin(CompositionalTwin)`，
复用父类 φ / 因果头 / 课程学习（点估计口径与 P1 逐位一致 → 增量干净归因到 σ 合成）。
predict 时 `σ_pred = σ_epi · g(·)`，g 两种拟合方式：

- **变体 1 · empirical（novelty 门控）**：在 20% ID 校准集上估欠缩放比
  `r(nd)=median|resid|/σ_epi` 作为 kNN 新颖度 nd 的函数（单调非减），`g(nd)=r(nd)/r(nd_ref)`。
  修复了父类 kNN **自匹配** bug（`_knn_dist` 取 k+1 近邻丢弃第 0 列），否则 med_dist≈0 → nd 塌为 0/爆为 1e9。
- **变体 2 · heteroscedastic（σ_epi 异方差重标定）**：诊断发现欠缩放与模型自身 σ_epi 呈
  负 Spearman 相关（-0.4），即「越自信越错」。门控 `g=(σ_ref/σ_epi)^β`，β 由校准集
  `log U ~ β·log(σ_ref/σ_epi)` 拟合（β≈-0.98 → `U∝σ_epi^{-1}`），使 |resid|/(σ·g) 在 ID 近似均匀。

两变体共用 `scripts/p4a_novelty_gate.py` 两臂受控对照（臂 A=P1 复现；臂 R=路 A），校准 q 均按判据
层级 α=0.95 估计。

## 2. 跑批结果

### 2.1 变体 1 · empirical（novelty 门控）—— 阴性

| 子集 | 臂 A(P1) cov@0.95 / ECE | 臂 R(路A) cov@0.95 / ECE | 判读 |
|---|---|---|---|
| id | 0.975 / 0.1748 | 0.975 / 0.1748 | 无变化（nd≈0 → g≈1） |
| ood_agent | 0.929 / 0.1357 | 0.929 / 0.2125 SAT | 恶化（nd 爆 1e9 → g 封顶 50 → 过宽） |
| **ood_action** | 0.999 / 0.2060 | **1.000 / 0.2125 SAT** | **仍饱和**，判据失败 |
| ood_neuro | 0.967 / 0.1697 | 0.967 / 0.1697 | 无变化 |

`verdict`: `routeA_cov@0.95=1.0, ece=0.2125 → P4A_ACCEPTED=false`。

**退化根因（非 bug，是特征空间结构）**：诊断显示 `nd_ref=0.000`、OOD `nd_rel=1.414e9`、ID `nd_rel=0.000`。
Norman perturb-seq 大量**精确重复细胞**（相同二元扰动 + 相同增益 → 相同特征向量），
in-distribution kNN 距离 ≈ 0（命中重复），OOD 新组合距离 = √2–√3。→ 新颖度在离散特征空间里
**本质是 0/1 指示**，无连续「严重度」梯度。门控被迫退化为二值开关（近训练=1，OOD=封顶 50），
无法按欠缩放连续撑大。

### 2.2 变体 2 · heteroscedastic（σ_epi 门控）—— 部分有效但判据仍失败

| 子集 | 臂 A(P1) ECE | 臂 R(路A) ECE | cov@0.95(臂R) | 判读 |
|---|---|---|---|---|
| id | 0.1748 | 0.1772 | 0.975 | 略退 |
| ood_agent | 0.1357 | **0.0655** | — | **显著改善**（σ_epi 门控命中其高欠缩放） |
| **ood_action** | 0.2060 | 0.1978 | **0.9972** | **仍超 0.97 上界、ECE>0.08，判据失败** |
| ood_neuro | 0.1697 | 0.1727 | 0.967 | 略退 |

`verdict`: `routeA_cov@0.95=0.9972, ece=0.1978 → P4A_ACCEPTED=false`。

> 注：ood_agent 改善是真收益，但其 `should_generalize=false`（不强制外推子集），非判据目标；
> 判据目标 ood_action（组合双扰动，应外推）未达。

## 3. 机制诊断（为何两种变体都失败 · 原理性）

**诊断脚本 `p4a_diagnose.py`**：在四子集上算逐样本欠缩放 `U=|resid|/σ_epi`，与各测试时可获得信号
做 Spearman 相关：

| 子集 | 欠缩放 median / p95 | vs σ_epi | vs novelty(nd) | vs 线性分歧 | vs 增益 g |
|---|---|---|---|---|---|
| id | 7.9 / 22.4 | **-0.41** | NaN（常量） | -0.07 | NaN |
| ood_agent | 9.2 / 25.7 | NaN（常量） | NaN（常量） | +0.03 | NaN |
| ood_action | 4.0 / 12.4 | **-0.35** | -0.15 | +0.04 | NaN |
| ood_neuro | 8.2 / 24.6 | **-0.40** | NaN（常量） | -0.10 | NaN |

三条铁证：

1. **新颖度（kNN 距离）是常量/NaN** —— 离散特征空间 + 重复细胞使其无连续梯度，无法作门控回归量。
2. **欠缩放与各子集强相关、但跨子集分布不匹配**：p95 欠缩放 id≈22、ood_action≈12、ood_agent≈26、
   ood_neuro≈25（注意 ood_action 反而最低）。→ 没有单一 q 能同时服务四子集。
3. **唯一弱信号 σ_epi 与欠缩放负相关（-0.4）** → 「越自信越错」。heteroscedastic 门控利用它改善了
   ood_agent，但 ood_action 的欠缩放 *低于* 校准 p95（12 vs 54），任何在 ID 校准上拟合的 q 都会
   **过覆盖** ood_action（实测 cov 0.997 > 0.97）。降 q 修 ood_action 会反过来破坏校准。

**根因（conformal i.i.d. 约束在本基准被打破的纯形式）**：
校准（ID）的 `|resid|/σ` 分布与 OOD 子集的分布**系统性不同**，且无任何测试时可得协变量能预测
该差异（新颖度常量、σ_epi 仅弱负相关且方向相反）。这恰好是 P4-1 已证明的「ID 校准不覆盖 OOD」
的估计器层镜像：**不仅 q 不可转移，σ 也不可转移**。

→ **路 A 未通过。** 与 P4-1（校准层）、P3-1b（virtual_twin 已修）共同构成：组合孪生（compositional_twin）
在 OOD 上的 epistemic 校准**原理性不可解**。

## 5. 结论与建议（诚实边界）

1. **PC-3 状态重定位为「原理性未解」**（非「待修」）。两条最 principled 的测试时重标定路径
   （novelty 门控、σ_epi 异方差重标定）均阴性；P4-1 的校准层路径更早阴性。三路独立证据闭合。
2. **唯一能修 PC-3 的路径需要 OOD 标注校准数据**——但 OOD 子集由定义对训练不可见，自相矛盾。
   即「在 OOD 上校准 OOD 区间」在当前范式下不可行。
3. **可接受的次优解 = 坚守 R4 闸门**（W33 §4.3）：OOD 子集区间标注「不可信」，仅点估计参与
   机制泛化判决。本基准上 `linear` 已是四子集区间全可用且点估计最优的预测器，OOD 结论应以点估计为准。
4. **停止在校准/门控层继续投入**（已排除：P4-1 分 subset q、路 A novelty/heteroscedastic 门控、
   P3-1 有界门控+封顶）。若 epistemic 校准确为硬需求，须改**结构性估计器**
   （距离感知集成 / 生成式 epistemic / proper-Bayesian 深度集成）——属新研究方向，超出当前 scope，
   建议单独立项而非在 compositional_twin 上继续手术。
5. **本 negative 不推翻既有证据**：P4-4（PC-1 结构路径耗尽）、P4-3（逆方差收缩阴性）、P3-1b
   （virtual_twin 已修）结论不变；仅把 PC-3 从「路 A 待攻克」降为「原理性未解、R4 兜底」。
