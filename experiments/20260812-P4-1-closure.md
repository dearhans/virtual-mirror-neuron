## 3. 核心诊断：localized q 退化的必然性（非 bug，是 conformal 的 i.i.d. 约束被打破）

运行日志直接暴露根因：

```
[p41] q_global@0.95=41.2597
[p41] q_local=id=41.2597, ood_agent=41.2597, ood_action=41.2597, ood_neuro=41.2597
```

四个子集的 `q` 完全相等 = 全局 `q`。脚本分配逻辑：
```python
med_arr = [median(nd) for s in SUBSETS]          # 各测试子集新颖度中位数
assign = argmin(|nd_c - med_arr|)               # 校准行 → 最近子集
q_local[s] = quantile(scores_c[分配到 s], 0.95)
```

**必然退化链**：
1. 校准行取自 `Xtr[cidx]`（训练分布内部 20%），其 `nd_relative`（新颖度）**全部处于训练分布内低位**；
2. OOD 测试子集（ood_action / ood_neuro）的新颖度中位数**显著更高**；
3. `argmin` 把每个校准行匹配到**最近的**测试子集中位数 → 因校准行 nd 全低于各测试中位数且 `id` 最低，全部归 `id` 箱；
4. `id` 箱含几乎所有校准行 → 其分位数 ≈ 全体分位数 = `q_global`；其余三箱 `mask` 为空 → 回退 `q_global_95`。

→ **所有子集 q 相等**。分 bin 在「校准集新颖度范围 < 测试集新颖度范围」时必然退化。

**这是 conformal 理论约束（校准集必须与目标分布 i.i.d.）在 OOD 上的实证失效**：要用 ID 校准去标定 OOD 区间，ID 校准集的新颖度无法覆盖 OOD，按新颖度分箱无意义。TRIZ「空间/局部分离」在此处结构性无效——分离维度（新颖度）在可用校准数据上无支撑。

## 4. PC-3 瓶颈重定位

| 假设 | 结果 | 结论 |
|---|---|---|
| PC-3 = 「全局 q 不适合 OOD 子集」（统一 q 过大） | localized q 退化回全局，区间不变 | ❌ 假设错 |
| 真正瓶颈 = 组合孪生 epistemic std **全子集一致**欠缩放 | q@0.95 = 41.26 → std 被低估 ~41×，且 ood_action/id/ood_neuro 同量级 | ✅ 确认 |

PC-3 是** epistemic 估计器缺陷**（深度集成在 OOD 上 confidently-wrong，std 坍缩），**不是校准层重标定能修的**。这与 P3-1b 对 `virtual_twin` 的发现（q@0.9=30.22，std 欠缩放 ~30×）是**同一类根因**，只是组合孪生的 std 被低估得更狠（~41× @0.95）。

**推论**：即便强行用 OOD 校准行（违反 i.i.d.）去估 localized q，也只是把「ID 校准外推失败」换成「OOD 校准数据不可用」——本项目无此数据设置，故 localized conformal 在当前架构下不可行。

## 6. 下一步建议（诚实，非粉饰）

P4-1 关闭了「校准层重标定」整类方向。要解 PC-3 只剩两条路：

1. **修 epistemic 估计器本体**（不做 conformal 重标定）：让 std 因新颖度而放大（novelty-gated std / P3-1 的 σ 门控在 OOD 上应更激进地撑大），使 `|y-mu|/std` 在 OOD 上回到名义尺度。代价高、且会与「std 撑大 → cov 下降但仍在饱和区」的历史拉锯。
2. **价值主张重定位**（推荐）：接受组合孪生在 OOD 上区间天然过宽是**深度集成固有特性**，不再以「紧凑可信区间追平线性」为卖点；改强调**可解释分解（φ 线性头 + 残差头） + 组间方差校准（var_ratio 保住）**——线性/MLP 给不了这两点，对齐获奖判据 A（白箱因果图）/ B（模块化可组合）。
