## 0. 一句话结论

## 1. 赛题速览（任务 / 数据 / 评测 / 规则）

### 1.1 任务形式化
- 输入：菌株 + 化合物 + 培养基 + 温度 + 处理时间 +（测量上下文：数据来源/仪器/板）
- 输出：**4,232 维蛋白质组 log2 强度向量**（5,243 过滤后；~20% 蛋白在 ≥80% 样本缺失）
- 任务类型：**OOD 条件回归/生成** —— 直接从条件生成响应，**不需要输入 control 样本**（control 是 Δ 计算的参照基准，由评测方持有）

### 1.2 数据规模
- 6 菌株 × 56 化合物（55 个化学扰动 + 对照）× 2 培养基 × 2 温度 × 6 时间点
- 训练集 5,920 样本（4 菌株 × 38 化合物）；训练+验证共 8,958
- 化合物正交划分：38 训练 / 6 验证 / 11 测试

### 1.3 验证场景（实体级正交划分）—— 与本项目 OOD 三轴一一对应

| 官方场景 | 定义 | 样本数 | 本项目等价子集 |
|---|---|---|---|
| val_chem_only | 已见菌株 + 未见化合物 | ~1,547（另有 ~1,293 计算子集） | **ood_action** |
| val_strain_only | 未见菌株 + 已见化合物 | — | **ood_agent** |
| val_both | 未见菌株 + 未见化合物 | **269（试金石）** | **ood_combo / ood_s3** |
| val_time | 时间外推 | — | 时间轴外推 |

⚠️ 教程明确：**内部研究必须分场景分别报告**，不能只给大样本场景主导的总分；val_both 是区分模型泛化能力的试金石——这正是我们「记忆 vs 机制」双栏报告的强制性要求。

### 1.4 评测指标（6 模块，权重精确化）—— 65% 围绕 Δ = 处理 − 对照

| 模块 | 内容 | 权重 |
|---|---|---|
| 绝对保真 | 绝对丰度 Global R² / PCC | 20% |
| **匹配对照原始 FC** | **Δ = ŷ_treat − y_control 的 PCC** | **25%** |
| 上下文均值残差 | 去除共享效应后的特异响应（化合物特异性） | 20% |
| 药物均值残差 | 菌株背景调制 | 20% |
| 双重未知·时间外推 | val_both + val_time | 10% |
| 高效应蛋白 DEP 检出 | 差异表达蛋白检出 | 5% |

关键认知：
- **Global R² 区分度极低**（蛋白均值基线 0.87，Matched Control 基线 0.98），所有模型接近天花板；
- 真正拉开差距的是 FC + 两个残差（65%），它们考察**化合物特异响应与菌株背景调制**；
- 参赛者只预测绝对丰度 ŷ_treat，Δ 由评测服务器用真实对照自动算。

### 1.5 双榜与统一排名（重要赛制信息）
- **封闭数据榜**：不依赖外部数据匹配 → 初赛主力（可行性高）；
- **开放知识榜**：引入基因组/SMILES 外部表征 → 复赛/决赛尝试；
- **统一排名**：虚拟细胞、小分子轨迹、材料智能体**三个方向同台评分**，归一化后按 **45（技术性能）/ 30（科学意义）/ 20（方法创新性）/ 5（开源贡献）** 统一打分，全赛道只决出一名算法赛题冠军。
- 每支队伍只能选一个方向提交；官网提交上限 3 次，以最后一次为准。

### 1.6 初赛提交物
- 方案说明文档 + 技术路线概述（**不强制提交代码**，可附初步实验/可行性验证）；
- 评委重点：独立理解与判断、取舍理由、归因分析（「这段话我能答辩时解释清楚吗？」）；
- AI 可用作辅助，但核心思考必须原创 —— 照搬教程/LLM 输出答辩无法自洽。

## 2. 教程路线提炼（基线 → 提分 6 创新点）

### 2.1 渐进路线
- **阶段 0**：数据对齐 + 蛋白均值基线 + Matched Control 基线（端到端首次提交，对齐赛题报告 ±5%）
- **阶段 1**：条件编码 MLP（one-hot → 2~3 层 MLP → mask-aware MSE；<1M 参数，单机分钟级）
- **阶段 2**：实体可迁移表征（菌株基因组 / 化合物 SMILES）→ 提升 val_both / val_strain_only
- **阶段 3**：残差分解 + 交互 + 批次校准 + 蛋白先验 → 提升 FC、残差类指标
- **阶段 4**：科学意义解读 + 生成式 / 主动学习 → 拉开 50% 的科学意义+创新性分

### 2.2 六条跨比赛通用经验
先简后繁 ／ 共享 encoder + 多头 ／ **loss 设计 > 模型结构** ／ 分桶 k-fold（同组不跨 fold）／ 后处理校准 ／ 单模型 + 固定种子（不迷信集成）

### 2.3 六大创新点（第五章，创新性主战场）
1. **残差分解架构**（强烈推荐）：ŷ = 共享应激响应 + 化合物特异残差 + 菌株调制残差 + 菌株×化合物交互项 —— **与评测模块一一对应**
2. **实体可迁移表征**：菌株→基因组（Peter et al. 2018, Nature 556:339–344 的 1,011 株；6 株从中挑选；DHY210 用 S288C 代理）；化合物→SMILES→Morgan FP / GNN / 预训练表征
3. **批次校准**：生物编码与观测校准（仪器/板/来源）双分支，additive offset
4. **蛋白侧结构化先验**：ESM embedding（4,232 蛋白序列）+ 通路注意力 + PPI 图
5. **生成式建模**：CVAE / Flow Matching / Diffusion → 分布 + 不确定度（争特别奖潜力）
6. **主动学习闭环**：模型推荐最有价值的实验 → 实验者补充 → 重训（AIVC 长期目标，初赛作「未来方向」阐述）

### 2.4 训练策略要点
- loss：mask-aware MSE + FC loss（1−Pearson）+ 残差正则
- 后处理：预测 − 同条件 control 均值 + 全局均值（稳定提升 FC）
- 验证：GroupKFold 按 (strain, chemical) 分桶；embedding shuffle/置零消融；防泄漏红线

## 4. 关键科学判断（教程没写、我们有实证的部分 —— 这是差异化武器）

### 4.1 「残差分解架构」的成败点：交互项
教程把架构写为「共享 + 化合物特异 + 菌株调制 + **交互项**」，但**没有给出交互项该怎么设计、值多少分**。我们已有决定性证据：

- **P1（纯加法基 φ）**：在真实 Norman 双扰动上，加法先验 RMSE≈0.636 与最佳基线 0.627 持平 —— **纯加法分解不会赢**；
- **P2（+对称交互头 ψ，不依赖基因对身份）**：0.632，仍与线性持平 —— **交互头能学到可泛化 epistasis，但真实信号量小**；
- **epistasis 合成扫描（决定性）**：ε=2.0 时黑箱 MLP 10.9 vs P2 24.4（2.2×）—— **富 epistasis 时结构化先验不敌黑箱**；结构化先验仅在响应确为加和的 regime 占优；
- **MISATO 结合域（跨域验证）**：combo_ood 上加性 ridge 50.9 ≈ 均值 51.0（退化为平凡预测器），黑箱 MLP 44.4/KNN 44.8 —— **蛋白–配体相互作用能不可加性分解**。

**对赛题的推论**：酵母蛋白质组的「菌株×化合物」扰动大概率是**中等偏弱 epistasis**（菌株是遗传背景、不是另一个强扰动），因此：
- 纯残差分解（共享+菌株+化合物，无交互）≈ 教程推荐的基线天花板，**必须做交互项**；
- 交互项设计应**避免按 (菌株, 化合物) 身份查表**（对 val_both 零外推），采用**依赖实体表征的对称交互**（如 ψ(genome_emb)·ψ(smiles_emb)）—— 这正是我们 P2 的教训；
- **不要押注「加法先验击败黑箱」**（精度叙事赢面低，情景 A），把故事定位在**机制可解释 + OOD 泛化 + 消融量化**（情景 B+C）。

### 4.2 评测权重 = 架构设计说明书
65% 分数围绕 Δ：**模型应直接以 Δ 为监督目标**（适配器已默认 target=Δ），绝对丰度作为辅助头。后处理用「预测 − control + 全局均值」校准 —— 这是零训练成本的稳定提分。

### 4.3 分场景报告 = 我们的双栏报告
教程强制分 val_chem_only / val_strain_only / val_both 报告 —— 与「记忆 vs 机制」双栏完全同构。我们比教程更进一步：**带 bootstrap 95% CI + 校准（ECE/覆盖率）**，这直接命中评审维度③（证据质量）与范式创造奖（动态科学评测框架）。

## 5. 决策点与风险（必须先想清楚）

1. **只能选一个方向**：算法赛三个方向（虚拟细胞/小分子轨迹/材料智能体）同台、每队只选一个；且算法赛与开放探索赛是**两条不同路径**。桌面已有 BridgeMD 开放探索提交包（v2 问题定义文档 + 协议索引）—— **需要明确：主攻开放探索，还是切虚拟细胞算法赛？**
   - 虚拟细胞优势：数据 8/5 前下发、评测明确、我们有组合先验+OOD 框架的强映射；
   - 开放探索优势：已提交 v2、不依赖数据下发、范式创造奖叙事成熟；
   - 风险：切换方向 = 放弃已投入；虚拟细胞方向竞争烈度未知（Datawhale 官方教程 = 大量选手同模板）。
2. **数据下发时间**：教程默认数据已到手（Demo 用模拟数据）；若 8/5 下发，距离初赛 8/16 仅 ~11 天。
3. **外部资源可达性**：SMILES 抓取（PubChem/RCSB）、1,011 株基因组、SGD 蛋白序列、ESM 权重 —— **沙箱全部不可达**，必须本机或提前下载。

## 6. 行动清单（数据下发前后）

### 6.1 数据到手当天（优先级高 → 低）
1. 核对官方字段字典 → 补齐 `goai_virtualcell_adapter.py` 的 `COLUMN_MAP` / `CONTROL_TOKENS`（草稿已按 PDF p15-18 推断）；
2. 跑通蛋白均值 + Matched Control 基线，与赛题报告指标对齐（±5%）；
3. 数据卫生四步：sample_ID 对齐 → 仅训练行算缺失率过滤（5,243→4,232）→ mask 矩阵 → log2；
4. 跑条件编码 MLP（mask-aware MSE）作第一版端到端提交。

### 6.2 提分（赛题化迁移我们的资产）
1. **残差分解 = CompositionalTwin 赛题版**：共享头（control/均值）+ φ 加法基（菌株+化合物） + **ψ 对称交互头（依赖基因组/SMILES 表征，不查表）**，mask-aware 多目标 loss（MSE + FC-PCC + 残差正则）；
2. **化合物表征**：55 化合物名称 → 标准化 → SMILES（复用 fetch_misato_smiles.py 抓取逻辑）→ RDKit Morgan 2048 + 描述符（已装）；
3. **菌株表征**：6 菌株 → Peter 2018 1,011 株基因组（DHY210→S288C 代理，标注假设）→ k-mer / genome LM embedding；
4. **分场景报告 + bootstrap CI + 校准**：直接复用 benchmark_ood.py 报告管线，输出 6 模块×4 场景矩阵；
5. **消融**：φ 置零 / ψ 置零 / 表征 shuffle —— 量化每个组件贡献（评审②证据质量 + 教程 5.6.2 强制）。

### 6.3 科学意义 30% + 创新性 20%（拉开差距处）
- **外部数据虚拟实验**（教程评为「最高杠杆」）：挑 3~5 个训练集外、文献有明确蛋白质组响应的化合物 → 用模型预测 → 与文献对比 → 隐藏机理评估，争特别奖 —— **这正是我们项目「预测→验证→误差反馈」闭环的现成故事**；
- **机制解读**：用交互头 ψ 的激活找出「菌株×化合物」非加和的具体蛋白/通路（epistasis 定位），从指标报告升级为生物学发现；
- **主动学习**：用 Phase D 设计「下一批最有价值的实验」演示（信息量/不确定度排序）—— 直接响应赛题 FAQ Q12 的 self-evolving 诉求。

## 7. 对 goai_strategy.md 的增量结论
- 情景重估更新：**数据下发后，虚拟细胞不再是「纯等」** —— 我们有一整层现成资产可插拔，且教程的提分主架构 = 我们已实证的 CompositionalTwin；

- 建议姿态：若数据按时下发 → 虚拟细胞算法赛主攻（资产映射最强），开放探索作保底；若下发延迟 → 维持开放探索。
