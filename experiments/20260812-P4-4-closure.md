## 0. 动机

P4-3 收缩「保判别力、不补精度」被拒后，W33 §7 与 P4-3 结案 §4 一致指向：**PC-2 / PC-1 的精度端改由 P4-4 的结构解承担**，而非再调收缩强度（容量非瓶颈已被多次证明）。

P4-4 的设计意图：把加法基 φ 拆成
- **线性头** `W_lin·p + b0`（LinearRegression，仅单扰动行拟合）——在 held-out 对（ood_action，两基因均见过单扰动）上靠加法组合天然外推；
- **机制残差头** `r(p)`（MLP 集成，单扰动行拟合 `z − 线性头(p)`）——只补线性解释不了的非线性。

预期：残差头在 held-out 基因上 ≈0，外推完全交给线性头 → 组合孪生在 `ood_action` **首次追平线性**。

---

## 1. 方法

- 子类化 `CompositionalTwin`，仅替换 `_phi`：`φ(p) = 线性头(p) ⊕ 残差头(p)`。
- 纯结构改动，**不含 P4-3 收缩**（与 P4-3 分两次跑、分别记账，归因干净）。
- 镜像 p43 口径：GATE_REPRO 复现闸门（臂 A 与 canonical 逐位复现，tol 1e-9）、事前锁定判据。
- **判据（预锁定，`criterion_prelocked`）**：`ood_action` 子集，组合孪生 RMSE[CI] 与 **linear** **CI 重叠或更优**（`ci_overlap_or_point_better`）。

## 3. 结论（诚实分层）

### 3.1 判据形式上达成，但属「弱达成」
`P44_ACCEPTED: true` 来自 **CI 重叠分支**，不是点估计更优。**重叠区只有 [0.6298, 0.6310] 一条窄带**——P4-4 区间主体 [0.6310, 0.6397] 仍高于线性 [0.6218, 0.6310]。即「不再被线性以不相交 CI 排除」，而非「追平/超越线性」。线性点估计 0.6265 仍是全场最低。

### 3.2 双通路结构相对 P1 孪生无显著增加益
P4-4 在所有子集上相对 P1 孪生均微优（delta −0.0004 ~ −0.0010），但**全部落在 CI 重叠带内**（不可区分）。原因是：**P1 孪生的 φ 本身已近似加法性**，残差头在 held-out 对上几乎无额外信号可学。双通路只是把已有的近似加法结构「显式化」，没有新增外推能力。

### 3.3 PC-1 结构改造路径就此耗尽（核心结论）
为解 PC-1（线性 vs 组合孪生 OOD 差距 / 加法基 φ 容量不足以同时承载「记忆分布」与「远端外推」），我们已穷尽 4 类结构改造：

| 招 | 改动 | ood_action 相对 P1 | 线性是否仍赢 |
|---|---|---|---|
| P3-1 | σ 解耦 + 有界门控 | ood_agent 坍缩消，ood_action 持平 | 是 |
| P4-2 | 共扰动插补 | 精度略降 | 是 |
| P4-3 | 逆方差收缩 | 精度未回补 | 是 |
| **P4-4** | φ 双通路 | **不可区分（−0.00046）** | **是** |

**四招全部「保判别力（var_ratio）不补精度/OOD」，无一让组合孪生在 ood_action 追平线性。** 这证明 ood_action 上线性（0.6265）领先组合孪生（0.6351）约 0.009 的差距是**监督信号边界，非模型容量边界**——线性基线在全训练行（含共扰动）拟合，而组合孪生线性头只在单扰动行拟合（held-out 基因系数靠组合给出），后者少了共扰动行的额外信息。

### 3.4 与获奖作品命题再次吻合
本结果与 `MEMORY.md`「获奖作品思维方式」的跨数据集一致命题完全一致：**线性/加法 = 最稳远端外推器；黑箱 OOD 崩塌**。组合孪生在 ood_action 追不上线性，恰是「远端外推靠加法组合、不靠机制容量」的又一次实证。

## 4. 对计划的连带影响

- **PC-1 结构路径关闭**：停止在「加法基 φ 结构上再做手术」以图追平线性 OOD。边际收益已 < CI 半宽，继续投入是边际递减陷阱。
- **组合孪生的价值主张需重定位**：不再以「ood_action RMSE 追平线性」为卖点（做不到），改为强调 **可解释分解（φ + 残差）+ 组间方差校准（var_ratio 保住）**——这是黑箱线性/MLP 给不了的。这恰好对齐获奖判据 A（可解释白箱因果图）与 B（模块化可组合）。
- **P4-1（subset/localized conformal）仍是真正的开放缺口**：PC-3（ood_action 区间饱和）独立于 PC-1，判据 `ood_action cov@0.95 ∈ [0.93,0.97] 且 ECE<0.08` 仍未达成（本次 P4-4 的 ECE 0.1946 >> 0.08）。**下一步应转 P4-1**，不再纠缠 PC-1 结构。
- **conformal q 异常（旁注）**：P4-4 的 `q=123.55` 远高于 P1 `30.05`——残差头集成放大了预测方差，区间需更宽才覆盖 → 看似校准更好（覆盖率高）实则过度保守。这不改变 ood_action RMSE 判据，但提示双通路会「以方差换覆盖」，calibration 收益是虚的。
