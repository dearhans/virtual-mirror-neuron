## 0. 假设与事前锁定判据（W33 §3.10）

**待检假设**：compositional_twin 的 n_ensemble 个 MLP 在**完全相同数据**上独立训练 → 收敛同一函数 → OOD 方差塌缩（PC-3 根因）。P5-B 在**构造期**注入多样性：训练成员 m 时按局部训练支撑稀疏度 w(x)（连续 kNN 距离，非路 A 二值 novelty）加权样本，并叠加逐成员平滑区域偏好 u_m(x)（低维随机投影 + 随机相位），使不同成员在不同稀疏区被差异化强调 → 稀疏/OOD 区天然分散、密集 ID 区仍一致。

**判据（与路 A 同，公平比较）**：ood_action 上 P5-B 的 覆盖@0.95 ∈ [0.93,0.97] 且 ECE < 0.08；且 id/ood_agent/ood_neuro 相对 P1 不退化（覆盖@0.95 不跌破 0.85、ECE 不爆）。

## 1. 实现

`code/model/compositional_p5b.py`：`CompositionalTwinP5B(CompositionalTwin)`，复用父类 φ/因果头/课程学习。仅重写 `fit`（在父类预处理后、训练前先建 kNN 密度得连续稀疏度 w(x)∈[0,1]，再为每成员 m 算平滑区域偏好 u_m=sigmoid(Z·a_m+b_m)，`sample_weight = clip(1+λ·w·(2u_m−1), 0.01, ∞)`）与 `predict`（返回**原始集成 epistemic**，无 P3-1 门控/封顶，干净归因）。

`scripts/p5b_density_injection.py`：镜像路 A 两臂受控对照（臂 A=P1 复现；臂 R=P5-B），λ∈{0.01,0.05,0.1} 三档扫描；每子集报 RMSE/覆盖/ECE + **多样性注入诊断**（σ_epi 比、欠缩放比）。

## 3. 机制诊断（为何失败 · 诚实）

**诊断证据（来自 `w36_p5b_run.log` + 多样性注入诊断字段）**：

1. **λ 零效应** = `sample_weight` 机制未触及密集主体。w(x) 仅在稀疏/OOD-like 区非零，而此类点在训练集中是**极少数**；密集区 w≈0 → 所有成员在 99% 的主体上训练完全一致 → 收敛到同一函数 → 低方差 → σ 小。逐成员 u_m 仅扰动少数稀疏点，无法撼动主体拟合。
2. **σ 反而变小（0.556×）** = 方向反了。重加权没有制造成员*分歧*（这正是我们想要的），反而因少数点扰动使集成略趋同。
3. **根因 = 工具链限制，非概念错误**：`sample_weight` 重加权**无法注入负相关的成员分歧**（negative correlation learning 需要修改损失项 `(f_m−f̄)(f̄−y)`，sklearn `MLPRegressor` 不支持）。密度感知多样性的*概念*成立，但当前 numpy/sklearn-only 工具链表达不了所需的 decorrelation 损失。

> 与路 A 的区别：路 A 是**测试时**乘门控 g(·)（已证 novelty 二值 / σ_epi 弱负相关，σ 在 OOD 不可转移）；P5-B 是**构造期**注入多样性（治本方向正确），但 sklearn MLP 的 sample_weight 不足以实现所需的成员 decorrelation。

## 4. 判决

```
λ=0.01/0.05/0.1: ood_action ECE 均=0.6872 (目标<0.08)  cov@0.95 饱和(≈1.0)
σ_epi 比(P5B/P1)=0.556 (方向反: 更小而非更大)   λ 零效应
P5B_ACCEPTED = false   (三档全阴性, best_lambda=null)
```

→ **P5-B spike 阴性。** 概念（密度感知多样性）合理，但本实例化（sklearn sample_weight 代理）无法注入成员负相关；proper 实现需 custom 训练循环（NCL/SGLD），超出当前 sklearn-only 工具链。

## 5. 对 P5 路线的影响与待决策

- P5-B 的失败暴露一个**工具链层级**瓶颈：`compositional_twin` 的集成用 sklearn `MLPRegressor` 训练，无法表达 decorrelation / Bayesian 后验所需的损失修改。这意味着：
  - **P5-A（proper-Bayesian / SGLD）**：同样需要 custom 训练循环（SGLD 采样权重），**比 P5-B 更重**的工具链升级。
  - **P5-C（生成式 epistemic）**：σ(x)=σ_id·h(1/q(x)) 是**测试时**密度门控，q(x) 用 GMM/MAF 拟（sklearn `GaussianMixture` 可用）。但路 A 已证「任何测试时协变量都无法预测欠缩放」（novelty 常量、σ_epi 弱负相关）——GMM 密度 q(x) 本质是对局部密度的平滑估计，与 kNN novelty 同源，**大概率撞同一堵墙**。
- **建议（待用户决策，serotonin 停止信号触发）**：
  1. **投资 proper NCL 实现**（custom numpy/torch 训练循环，注入负相关损失）——治本但 scope 升级；或
  2. **试 P5-C（GMM 密度门控，sklearn 可行）**——便宜但大概率撞路 A 同墙；或
  3. **触发 kill-switch**：三机制中 P5-B 已阴性、P5-A 需工具链升级、P5-C 大概率同墙 → 停 P5、接受 R4 闸门（OOD 区间标「不可信」，仅点估计参与机制泛化判决），把阴性写成可发表级发现（"ID-only 训练下 OOD epistemic 校准结构性不可行"）。
