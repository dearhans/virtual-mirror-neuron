# TRIZ 矛盾分析 · 虚拟镜像神经元项目

> 目的：把项目反复出现的「记忆 vs 外推」张力翻译成 TRIZ 矛盾语言，分类已解/未解矛盾，
> 给周报「未解矛盾」项与湿实验方案提供理论支撑。对应项目硬约束：
> **所有预测必须区分「记忆」（in-distribution）与「机制泛化」（OOD）。**

---

## 1. 核心物理矛盾（提升级）

**同一个响应预测函数 `f`，在同一时刻必须同时具备两种对立属性：**

- **记忆**：在训练分布内（已见扰动 / 已见基因 / 已见批次）高保真复现真实响应——要求模型**选择性记住**局部细节。
- **外推**：在训练分布外（未见扰动组合 / 未见基因 / 未见批次）仍能给出合理响应——要求模型**忽略**训练细节、依赖通用机制。

> 矛盾焦点：模型的**同一组参数**既要「记住」又要「忘掉」训练集的特定结构。
> 这就是本项目反复撞墙的物理矛盾，不是工程 bug。

| # | 想改善的参数 | 恶化的参数 | 在项目中的体现 |

## 3. 已采用的发明原理（已解部分）

| 原理 | TRIZ 编号 | 项目落点 |
|---|---|---|
| **分离原理**（空间/条件/尺度分离） | #1 分割 | VirtualTwin 把「记忆」与「机制」拆到不同尺度：细胞非线性 φ 局部保真（记忆），动作对称性 + 调质乘法因果头全局泛化（机制）。这是本项目最核心的破局招。 |
| **合成 / 嵌套** | #5 / #17 | 多尺度结构化 + 调质增益 head（baseline/dopamine/serotonin → 乘法 g），用结构先验替代纯数据记忆。 |
| **预先作用 / 反向作用** | #10 / #13 | do-演算反事实 + 不确定性前置（集成方差 + 新颖度距离），在「预测之前」先判断「这是记忆还是外推」。 |
| **反馈** | #23 | 每周导出湿实验方案（光遗传/钙成像）→ 实验数据回流修正模型。闭环是外推能力的最终裁判。 |

## 4. 未解矛盾与破局路线（诚实标注）

### 4.1 unseen gene（ood_agent）—— 待破物理矛盾
- **现状**：完全新基因身份，训练集中无任何机制锚点 → 当前框架只能记忆、**标「不强制外推」**。
- **破局路线（TRIZ 参数变化 #35）**：把基因从 one-hot 身份提升为**可泛化特征**（基因功能注释 / 通路 membership / 序列 k-mer / 蛋白结构嵌入）。
  类比化合物描述符（见 `code/data/goai_compound_features.py`）：让 unseen gene 落在「已知基因特征空间」的邻域，靠插值外推。
- **状态**：🟡 未实现（需要基因功能注释数据源，待接入）。

### 4.2 双重未知（GOAI S3：unseen strain + unseen compound）
- **现状**：两个 OOD 轴同时触发，当前框架双重失守 → 只能记忆。
- **破局路线**：菌株特征（基因型/代谢背景 embedding）+ 化合物描述符**双拼进 P**，把双重离散未知降级为连续特征空间邻域问题。
- **状态**：🟡 化合物侧已写预取桩（见 4.3），菌株侧待做。

### 4.3 纯 one-hot 化合物在 unseen compound（S1/S3）只能记忆
- **现状**：化合物以 one-hot 进 P → unseen compound 无任何信息 → 必然记忆失效。
- **破局路线（参数变化 #35）**：`goai_compound_features.py` 拉 PubChem 描述符（MW/LogP/TPSA/HBA/HBD/环数…）+ MoA 类别，拼进 P。
  使 unseen compound 可通过描述符邻域外推。**这是冲 GOAI 开放知识榜的硬前提。**
- **状态**：🟢 桩已写，待数据到手验证。

### 4.4 校准在复杂 OOD 上可能欠校准
- **现状**：ECE 用简单基线（均值/线性）做校准参考，复杂 OOD（ood_action 双扰动组合）上区间覆盖率可能偏离名义值。
- **破局路线**：分子集独立校准（每个 OOD 轴单独 fit 标度）、引入 conformal prediction 给出有限样本有效覆盖。
- **状态**：🟡 部分实现（分子集 RMSE CI），conformal 待做。

## 5. 给周报 / 方案的使用方式

- 周报「未解矛盾」项直接引用 §4 的 🟡 条目，按 TRIZ 矛盾编号（T1–T3、物理矛盾）归类。
- 湿实验方案每条实验要标注它**检验的是哪条矛盾**：
  - 检验「分离原理是否成立」→ E1（乘法调质因果头）、E2（镜像对称性）。
  - 检验「参数变化是否破记忆」→ E3（组合双扰动）、GOAI S1/S3（化合物描述符外推）。
  - 检验「反馈闭环」→ 全部实验的回流修正。
- 任何 OOD 结论必须带 bootstrap 95% CI；CI 重叠视为不显著（避免过拟合式误判）。
