### 1.4 三条硬约束核查

1. **记忆 vs 机制分离**：✅ 显式双栏。真实基准下**唯一**机制检验轴 `ood_action` 由「坍塌」修复为「与基线持平」，但仍未达机制证据阈值（CI 重叠）。
2. **OOD 强制**：✅ 含 `ood_agent / ood_action / ood_neuro` 三类；真实基准语义严格对应「未见基因 / 组合双扰动 / 未见批次」。
3. **不确定度强制**：✅ 全 RMSE 带 95% CI；§3 另报 ECE / 覆盖率。

### 1.5 关键结论（诚实、决定性）

- **P1（基准重设计 + φ 剥离动作轴）消除了 `ood_action` 坍塌假象**，使基准公平；P2（基因对交互头）证实真实 epistasis 信号**量小**（交互头仅把 RMSE 从 0.636 → 0.632，非显著）。
- **组合 / 加法先验只在「响应确为加和」时才是有效归纳偏置**：真实 Norman 响应由单基因效应**线性主导**，故线性基线已捕捉大部分信号，结构化先验**无 RMSE 胜势**。
- **决定性证据来自 epistasis 扫描**（`experiments/epistasis_sweep.md`）：注入扰动级双线性 epistasis 时，黑箱 MLP 随强度单调反超结构化模型（ε=2.0：MLP 10.9 vs P2 24.4，2.2×）；结构化先验**仅在纯加法 regime（ε=0）占优**。→ 真实 Norman 的「持平」正是「epistasis 小、加法主导」的必然结果。
- 07-31 周报所称「`ood_action` 被线性反超 = 物理矛盾最尖锐暴露」**需修正**：真实数据中它是「加法主导 → 无机制差异」，而非「模型不会组合」。矛盾并未消失，但**性质变了**（见 §4）。

### 4.1 矛盾定性更新：**物理矛盾（Physical Contradiction）** 性质已变

> 同一对象（扰动响应预测模型）在同一参数（泛化能力）上，要求它既记住训练分布又外推未见条件。

- **07-31 误判**：把 `ood_action` 坍塌归因为「模型不会机制组合」（记忆 vs 外推的尖锐矛盾）。
- **08-01 修正**：真实公平基准下 `ood_action` 已修复为「与线性持平」，坍塌主因是**(a) 不公平基准 + (b) 真实 epistasis 信号小**（P1/P2 + 扫描量化）。矛盾从「模型不会组合」降级为更本质的——

### 4.2 更深的未解矛盾：**归纳偏置的 regime 依赖**

| 维度 | 纯加法 regime（ε=0 / 真实 Norman） | 富 epistasis regime（ε 大） |
|---|---|---|
| 结构化 / 组合先验 | ✅ 校准好、RMSE 占优（合成）或持平（真实） | ❌ 退化为与线性同效、远逊黑箱 |
| 黑箱 MLP | ❌ 逊于结构化 | ✅ 随 epistasis 强度单调反超 |
| 线性基线 | ✅ 真实数据已足够 | ❌ 漏掉非线性交互 |

→ 矛盾落点从「记忆 vs 外推」转为 **「机制先验的适用边界」**：先验在已知结构（加法）下诚实且校准良好，但在未知/富 epistasis 结构下既无精度优势、又过度保守。

### 4.3 可用的 TRIZ 发明原理（破法 = 条件 / 时间 / 系统级分离）

| 原理 | 本项目落点 | 当前进度 |
|---|---|---|
| **条件分离**（按 regime 选模型） | 加法主导数据 → 用结构化先验（校准好）；富 epistasis 数据 → 用灵活黑箱 + 诚实标注「无机制证据」 | 🟡 部分（已识别 regime，未自动化 regime-gated 选型） |
| **时间分离**（先记忆后机制蒸馏） | 周报→湿实验→回流；先用线性/结构化拿基线，再按需上黑箱 | ✅ 本自动化即仪器 |
| **系统级分离**（记忆组件 / 机制组件解耦） | 结构化先验管校准与已知结构，黑箱管未知非线性 | 🟡 架构未融合 |
| **局部质量**（高新颖度处强化机制先验 / 放宽区间→修正为收紧） | 原「新颖度撑宽」过头（§3 过覆盖）→ 改为子集自适应校准 | 🔴 待修（OOD 过覆盖） |
