# 标准作业流程 · SOP（闭环版）

本 SOP 把 `CHARTER.md` 的硬约束落为每周可执行的步骤，并接入 mirror-neuron 自学习引擎。

## 阶段 A · 数据整理与基准复现
1. 收集电生理 / 钙成像 / snRNA-seq，按 `data/` 规范存放（大文件不入库）。
2. 定义因果图：节点 = 神经元 / 突触 / 调质；边 = 连接；扰动 = 图上的 `do-` 干预。
3. 复现简单基线（线性、均值、最近邻）作为**记忆基线**，记录 in-distribution 指标。

## 阶段 B · OOD 外推评测（硬约束）
1. 切分 OOD 子集：未见动作 / 未见主体 / 新调质状态。
2. 同模型在 OOD 子集上评测，与阶段 A 基线对比。
3. **双栏报告**：左栏「记忆」（in-distribution），右栏「机制泛化」（OOD）。差额即机制证据。
4. 输出**校准后不确定度**（置信区间 + 校准曲线），参考 Shift Bioscience metric calibration。

## 阶段 C · 湿实验验证（闭环）
1. 从当前模型挑 Top-K 最高不确定度 / 最高信息增益的预测。
2. 转化为可执行方案：`wetlab/<YYYY-Www>.md`
   - 靶点（光遗传 / 钙成像）
   - 刺激参数（频率、强度、时程、组合扰动设计）
   - 预期响应 + 不确定度 + 证伪条件
3. 执行湿实验，记录真实响应与误差。

## 阶段 D · 误差回流与自学习
1. 把本轮（context / action / outcome / feedback）写入 mirror-neuron 观察库。
2. 调用 `suggest()` 为新 OOD 条件匹配历史策略；`evolve()` 更新策略权重。
3. 误差作为下一轮训练 / 校准的监督项，回灌阶段 A/B。

## 每周节奏（自动化驱动）
- **文献监测**：更新 `references/`，捕捉 virtual cell / perturb-seq / OOD 新方法。
- **周报**：执行「阶段 C.2」导出预测清单 → `wetlab/` 方案，并汇总未解矛盾。
- **OOD 基准评测**（强制）：重跑阶段 B，对比基线，输出校准指标到 `experiments/`。

## 卡点修正（TRIZ）
任一步骤卡住 → 回到 `methodology.md` §2 做矛盾分类 → 选分离 / 发明原理 → 再推进。禁止用「再加一层网络」掩盖机制缺失。
