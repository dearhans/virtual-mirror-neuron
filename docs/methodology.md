# 方法论 · Methodology

把「虚拟镜像神经元」从生物直觉变成可计算、可证伪、可外推的研究对象。本文档是 `CHARTER.md` 硬约束的方法论支撑。

## 0. 总纲：先问对问题
研究的起点永远是问题，不是方法。本项目唯一不可让渡的问题是：

> **一块神经基质为什么既能编码「我在抓花生」又能编码「我看你抓花生」？**

这不是装饰性发现，而是「自我 / 他者」在计算上同源的直接证据。所有下游建模都必须能回到这个问题作答，否则就是炫技。

---

## 1. 七层主线（逐层可计算化）

### 层 1 · 现象层（死磕悖论）
- 目标：把镜像放电的「自我 / 他者同源」确立为待解释现象，而非默认前提。
- 产出：一份可证伪的现象陈述 + 对照数据集（自我执行 vs 观察他人执行的神经记录）。

### 层 2 · 抽象层（翻译成可计算对象）
- 单神经元 = **预测编码单元**：维护对感官 / 运动结果的预测，并编码预测误差。
- 镜像性 = 感知与动作在**共享潜空间**里的等价 / 对称性（同一表征既可被「做」激活，也可被「看」激活）。
- 这一步决定你建的是**模型**（有可解释结构）还是**黑箱**（只能拟合）。本项目选前者。

### 层 3 · 建模层（多尺度虚拟孪生）
- 尺度链：离子通道 → 突触可塑性 → 微环路 → 宏观场。
- 把「给一个刺激 / 扰动」定义为图上的 **`do-` 干预**（因果图中的干预算子）。
- 数据同源：电生理（spiking）、钙成像（population dynamics）、单细胞核组学（cell-type & state）——与酵母赛题的 perturb-seq 是同一个思想：*扰动 → 测量 → 学因果*。

### 层 4 · 因果层（相关 → 可证伪预测）
- 工具：**`do-演算`** + **组合扰动**（multi-perturbation）把相关性升级为可证伪预测。
- 先验优先：虚拟细胞领域（GEARS、scPerturb、Virtual Cell Challenge 2025）已证明——带生物学先验的模型打得过纯端到端。本项目坚持**机制先验不可丢**。

### 层 5 · 泛化层（OOD 外推 = 机制试金石）
- 三类未见条件（OOD 子集，评测强制包含）：
  1. **未见动作**（unseen action）
  2. **未见主体**（unseen agent）
  3. **新神经调质状态**（novel neuromodulator）
- 判据：能外推 = 学到机制；只记住训练分布 = 无价值。

### 层 6 · 闭环层（绝不停在 benchmark）
- 预测 → 光遗传 / 钙成像湿实验验证 → 误差回流 → 再训练。
- 这是「AI 预测 → 湿实验验证」闭环的神经版。

### 层 7 · 意义层（反哺）
- 社会认知理论、孤独症机制假说、脑机接口、机器的内禀共情（「看样学样」）。

## 2. TRIZ 矛盾映射（遇到困难时的修正器）

当研究卡住，先把它归类为矛盾，而非凭灵感硬闯。

### 核心矛盾 = 物理矛盾
> 同一个模型，对「训练数据依赖度」这一参数需同时满足两个相反要求：
> - 要**高**（记住训练分布，否则基准都过不了）
> - 要**低**（外推未知，否则无科学价值）

**破法（分离原理）：**
- **时间分离**：训练 / 拟合阶段允许记忆；评测阶段强制切到 OOD regime，禁止「记忆红利」。
- **条件分离**：在 in-distribution 与 OOD 两种评测条件下切换同一模型，分别报告指标，显式暴露「记忆 vs 机制」差额。
- **系统级分离**：把「记忆模块」与「机制模块」解耦（如显式因果头 + 分布记忆旁路），分别可解释、可审计。

### 常见技术矛盾（改善 X 但恶化 Y）
| 想改善 | 会恶化 | TRIZ 提示 |
|---|---|---|
| 预测精度 | 可解释性 | 原理 1 分割 / 原理 24 中介物（因果头做中介） |
| 泛化外推 | 训练效率 | 原理 17 升维（潜空间对称性先验） |
| 多尺度一致性 | 计算成本 | 原理 35 参数改变（按尺度分配精度） |

### 理想度（IFR）北极星
```
理想度 = Σ(有益功能：机制可解释 + OOD 可外推 + 不确定度校准) / (Σ成本 + Σ有害：黑箱、过拟合、幻觉预测)
```
永远先定义「完美方案」再让步，不从折中起步。

## 3. mirror-neuron 自学习映射（SOP 的进化引擎）

把闭环迭代接入镜像神经元五层自学习框架（见 `../skills` 接入说明）：

| 生物机制 | 在本项目的对应 |
|---|---|
| 感知层（观察） | 记录每次闭环：上下文（模型版本 / OOD 子集）、动作（预测 + 刺激参数）、结果（湿实验误差）、反馈（显式 / 隐式） |
| 共振层（模式匹配） | 新 OOD 条件下，匹配历史相似扰动策略，复用成功方案 |
| 模拟层（内部预演） | 输出前对候选刺激参数做内部预演，预测成功率排序，标记高风险 |
| 可塑层（权重更新） | 据湿实验误差更新策略权重；显式纠正立即大幅更新 |
| 集成层（API） | `register / observe / query / suggest / feedback / evolve` |

目标：项目越跑越聪明——下一轮的预测清单比上一轮更聚焦、更校准。
