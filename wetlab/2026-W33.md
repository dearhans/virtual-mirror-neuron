## 2. 逐实验可执行协议

### 实验 1 · 乘法调质因果头验证 · do(neuromodulator=1.6)  `[E1-mult-gain]`

**选靶理由**：直接检验孪生因果头的乘法机制主张（g 作为增益因子乘入响应）。若成立，则模型学的是机制而非记忆——项目核心论点的试金石。

- **记忆/机制归类**：机制（因果头归纳偏置）
- **OOD 轴**：机制核心（因果头）

**靶点（Targets）**
- 光遗传：M1 第 V 层锥体神经元表达 ChR2（CamKIIα-ChR2-EYFP）；470nm 蓝光，200μm 光纤
- 钙成像：同群体 AAV1-Syn-GCaMP6s；双光子 30Hz 成像，ROI=M1 L5 锥体胞体

**刺激参数（Stimulation）**
- 频率：20 Hz
- 强度：8 mW/mm²（光纤尖端）
- 脉宽：5 ms
- 训练时长：3 s
- 组合/时序设计：固定光遗传激活；变量为调质增益
- 双光子成像时序：刺激前 5s 基线采集 + 3s 光刺激 + 刺激后 5s 后成像（30Hz 体成像，GCaMP6 不丢帧）

**神经调质**：浴注 5-HT（serotonin）标定至增益 1.6（对照 baseline aCSF=1.0、dopamine=1.3）

**预期响应 + 不确定度**
- 模型仿真：baseline 预测≈2.768，do(gain=1.6)预测≈2.647（缩放比≈0.956）。 种子基准下缩放比≈1（增益轴近乎无效应，与合成乘法设定不同）；湿实验须由实测判定该轴是否真实存在乘法机制——模型当前预测≈无。
- 不确定度处理：取反事实行 + 该增益子集 bootstrap 95% CI；OOD 下由新颖度撑宽。

**可证伪条件（Falsification）**：种子基准预测缩放比≈0.956（≈1，增益轴弱）；若湿实验实测同样≈1（无真实乘法效应），则「乘法因果头」在真实数据下不成立，须回 Phase A/B 重新审视该轴机制设定。

**对照设计（Controls）**：aCSF sham、ChR2-off 病毒对照、dopamine(1.3) 复核点

### 实验 2 · 镜像对称性验证 · do(action: self↔other)  `[E2-mirror-sym]`

**选靶理由**：检验尺度 B 的动作对称性（self/other 共享 φ，仅增益 mirror_k 不同）——「虚拟镜像神经元」的签名预测。

- **记忆/机制归类**：机制（尺度 B 对称性归纳偏置）
- **OOD 轴**：机制核心（镜像对称）

**靶点（Targets）**
- 光遗传：双侧同源群体（M1 同侧执行通路 + 对侧镜像通路）均表达 ChR2；双光纤独立控制
- 钙成像：GCaMP6f（快动力学）双侧 M1 同步双光子成像，30Hz

**刺激参数（Stimulation）**
- 频率：20 Hz
- 强度：8 mW/mm²（光纤尖端）
- 脉宽：5 ms
- 训练时长：3 s
- 组合/时序设计：self 与 other 各 20Hz/5ms/3s，伪随机交叉顺序
- 双光子成像时序：刺激前 5s 基线采集 + 3s 光刺激 + 刺激后 5s 后成像（30Hz 体成像，GCaMP6 不丢帧）

**神经调质**：固定 baseline（aCSF，增益 1.0）

**预期响应 + 不确定度**
- 模型预测 self 与 other 响应由 mirror_k 增益关联；二者响应比≈mirror_k。仿真参考缩放比≈1.0~1.6 量级（见反事实行）。
- 不确定度处理：self/other 配对差值的标准误；建议 ≥8 只动物配对。

**可证伪条件（Falsification）**：若 self/other 响应比显著偏离 mirror_k（或对称性消失、出现非对称非线性），镜像机制假设被否定，需重新设计尺度 B 对称性约束。

**对照设计（Controls）**：单侧 sham、非镜像区（V1）off-target 阴性对照

### 实验 3 · 组合双扰动机制验证 · do(双通路协同)  `[E3-combo]`

**选靶理由**：模型只见过单扰动，须用机制组合两条单扰动效应（而非记忆）。注：合成基准里 ood_action 被标为「不强制外推」，因它代表完全未见的新动作(imitation)，无法由已见单扰动分解；而本湿实验测的是「两个已见单扰动(M1、Striatum 各自训练过)的组合」——这是干净的「机制组合」检验，与合成 ood_action 缺口不同，故标记为应外推。

- **记忆/机制归类**：机制泛化（应外推）
- **OOD 轴**：组合双扰动（seen singles 组合）

**靶点（Targets）**
- 光遗传：M1-ChR2（470nm）+ 纹状体 D1-ChrimsonR（590nm，红光避串扰）；双色独立光纤
- 钙成像：下游读out群体（丘脑 VA/VL）GCaMP6s，双光子 30Hz

**刺激参数（Stimulation）**
- 频率：20 Hz
- 强度：8 mW/mm²（光纤尖端）
- 脉宽：5 ms
- 训练时长：2 s
- 组合/时序设计：单 M1 / 单 Striatum / 双激活（同时 与 50ms 延迟 两条件）
- 双光子成像时序：刺激前 5s 基线采集 + 2s 光刺激 + 刺激后 5s 后成像（30Hz 体成像，GCaMP6 不丢帧）

**神经调质**：固定 baseline（aCSF）

**预期响应 + 不确定度**
- 模型预测双扰动响应 = 机制组合值（非简单加和）。基准 RMSE(ood_action)=0.636
- 不确定度处理：取 ood_action 子集 RMSE 95% CI；组合条件不确定度更高（应重点验证）。

**可证伪条件（Falsification）**：若双扰动实测响应显著偏离机制组合预测（如简单线性加和、饱和或相互抑制），组合机制不成立 — 触发 SOP 阶段 D 误差回流 + TRIZ「系统级分离」修正。

**对照设计（Controls）**：单通路各条件、双色 off 病毒对照

### 实验 4 · 新调质外推验证 · ood_neuro（未见增益值）  `[E4-novel-mod]`

**选靶理由**：施加训练中未出现的调质（如 NE），检验乘法机制能否外推到未见增益值——对应 ood_neuro 子集（机制本应外推）。

- **记忆/机制归类**：机制泛化（应外推）
- **OOD 轴**：ood_neuro（新调质）

**靶点（Targets）**
- 光遗传：同 E1 的 M1-ChR2 设置
- 钙成像：同 E1 的 GCaMP6s 设置

**刺激参数（Stimulation）**
- 频率：20 Hz
- 强度：8 mW/mm²（光纤尖端）
- 脉宽：5 ms
- 训练时长：3 s
- 组合/时序设计：固定光遗传；变量为调质增益
- 双光子成像时序：刺激前 5s 基线采集 + 3s 光刺激 + 刺激后 5s 后成像（30Hz 体成像，GCaMP6 不丢帧）

**神经调质**：浴注 NE（norepinephrine）梯度对应增益 1.2/1.5/1.8（模型须外推乘法机制）

**预期响应 + 不确定度**
- 响应随增益单调乘法缩放（机制外推），而非退化为均值/线性基线。基准 RMSE(ood_neuro)=0.603
- 不确定度处理：取 ood_neuro 子集 RMSE 95% CI + 覆盖率（高新颖度处区间应撑宽）。

**可证伪条件（Falsification）**：若未见增益下响应不随乘法缩放（崩塌到均值/线性），外推失败 — 需强化调质乘法先验或扩充训练增益覆盖。

**对照设计（Controls）**：已知增益（baseline/dopamine/serotonin）复核 + aCSF 配对

### 实验 5 · 闭环光遗传反馈 · 实时钙信号触发刺激  `[E7-closed-loop]`

**选靶理由**：用闭环范式实时检测目标群体 ΔF/F 越过阈值即触发光刺激，验证因果头在动态反馈下的乘法增益机制（而非开环固定刺激下的记忆）。这是从「开环验证」迈向「在体闭环因果」的关键一步，直接对应 SOP 反馈原理(#23)，也是湿实验闭环回流模型误差的工程落点。

- **记忆/机制归类**：机制（闭环因果验证）
- **OOD 轴**：机制核心（闭环因果头）

**靶点（Targets）**
- 光遗传：M1 L5 锥体 ChR2（470nm）；实时反馈控制器（基于钙信号 ROI 阈值触发光刺激）
- 钙成像：GCaMP6f（快动力学 ~120ms 上升）支撑闭环低延迟；双光子 30Hz 体成像 ROI=M1 L5

**刺激参数（Stimulation）**
- 频率：20 Hz
- 强度：8 mW/mm²（光纤尖端）
- 脉宽：5 ms
- 训练时长：3 s
- 组合/时序设计：闭环：当 ROI ΔF/F>0.3 触发 20Hz×3s 光刺激；对照开环固定刺激
- 双光子成像时序：基线 5s + 闭环窗口 10s（刺激由内源活动触发，jitter±200ms）+ 后成像 5s（全程 30Hz 体成像，刺激期不丢帧）

**神经调质**：固定 baseline(aCSF)；可选 dopamine(1.3) 复核增益

**预期响应 + 不确定度**
- 闭环下当内源活动强时刺激增幅被调制（乘法增益仍成立）；触发后 ΔF/F 与开环 E1 增益量级一致。
- 不确定度处理：闭环事件触发 jitter ±200ms；每条件 ≥30 次闭环 trial 的触发后 ΔF/F 均值±SEM。

**可证伪条件（Falsification）**：若闭环触发后响应与开环无差异（增益不随内源活动调制），因果头乘法机制在动态反馈下失效 → 须修正因果头为状态依赖形式。

**对照设计（Controls）**：开环同参数对照、ROI 随机负位对照、sham

**刺激参数（Stimulation）**

- 强度：8 mW/mm²（光纤尖端）
- 脉宽：5 ms
- 训练时长：3 s
- 组合/时序设计：固定 E1 参数

**选靶理由**：在 1.0/1.3/1.6/2.0 增益梯度上刻画响应，校准因果头乘法机制并绘制剂量-响应曲线。

- **OOD 轴**：机制核心（因果头校准）

**靶点（Targets）**
- 光遗传：同 E1 设置
- 钙成像：同 E1 设置

**刺激参数（Stimulation）**
- 频率：20 Hz
- 强度：8 mW/mm²（光纤尖端）
- 脉宽：5 ms

- 组合/时序设计：固定光遗传；变量为调质增益梯度

**对照设计（Controls）**：各增益 aCSF 配对、sham

## 3. 闭环与不确定度声明（硬约束）

- **参数现实性**：文中光遗传（470/590nm、5–15 mW/mm²、5ms 脉宽、20Hz、2–3s 训练）与钙成像（GCaMP6f/6s、双光子 30Hz）为小鼠在体/脑片典型量级，须按实际制备（病毒滴度、光纤定位、麻醉状态）标定；增益 1.0/1.3/1.6/2.0 为 SCHEMA 调质映射值，真实浓度须通过剂量标定实验确定。
- 所有 OOD 结论均带 bootstrap 95% CI；CI 重叠视为不显著，避免过拟合式误判。
- 不确定度 = 集成 epistemic + 新颖度(OOD) 合成；未见条件下区间应撑宽（缓解黑箱过度自信）。
- **诚实标注**：本方案所有「预期响应」数值来自种子基准的仿真预测；真实 OOD 基准（已就位）跑通后须复核预测值与不确定度再执行。
- 执行后把实测响应与误差写回 Phase D（mirror-neuron 观察库），调用 `suggest()`/`evolve()` 更新策略权重，并作为下一轮训练/校准的监督信号（Phase A/B）。

## 4. 执行顺序建议

1. **E1 + E6**（同设施，增益梯度先行校准因果头）→ 2. **E2**（镜像对称性）→ 3. **E3**（组合双扰动，最难，留足样本）→ 4. **E4 + E5**（外推子集，可在同批动物扩展）→ 5. **E7**（闭环反馈，验证在体动态因果，依赖 E1/E6 标定）。

## 5. 如何解读与本方案否决条件

### 5.1 数值化否决规则（执行前团队须共识）

- **R1 显著性**：任何实验，模型预测 95% CI 与对照/基线预测 95% CI 重叠 → 视为不显著，不得宣称机制成立。
- **R2 外推失败触发**：某 `ood_*` 子集 virtual_twin RMSE 相对 `id` 子集退化 > 50%（或 CI 完全不覆盖基线 RMSE），触发 SOP 阶段 D 误差回流 + TRIZ 修正（详见 docs/triz_contradiction_analysis.md）。
- **R3 可证伪命中**：下表任一「否决条件」被实测满足，对应机制假设即被否定，须回 Phase A/B 修正后重跑。

### 6.2 三处更正（脚本模板 vs 工件不符）

**更正① · E2 镜像对称性的模型预测是「零效应」，不是「1.0~1.6」**
`experiments/20260810-benchmark.json` 的 `counterfactual.rows` 显示 `do_action_other_pred` 与 `pred_base` **逐位相等**
（2.768→2.768、2.855→2.855、2.745→2.745）。即当前模型的 mirror_k 已退化为 **恒等映射 1.000**，动作轴无任何效应。
§2 实验 2 中「仿真参考缩放比≈1.0~1.6 量级」属模板残留，不成立。
→ **E2 的真实证伪结构是反向的**：模型预测 self/other 比值 = 1.000；若湿实验实测比值显著 ≠ 1，则**模型的镜像轴被证伪**（漏掉了真实存在的对称性机制），而非镜像假设被证伪。这是本项目签名预测当前最薄弱的一环。

**更正② · R2 否决规则对 virtual_twin 的真实失效模式结构性失盲**
§5.1 R2 以「virtual_twin RMSE 相对 id 退化 > 50%」为触发器。实算退化为
ood_agent **19.04%** / ood_action **14.87%** / ood_neuro **5.84%** —— 全部远低于 50%，R2 永不触发。
但 virtual_twin 的真实失效是**区间失效**：ECE 0.706–0.733、覆盖@0.9 仅 0.065–0.097（名义 0.90）。
即：点估计看着「没退化」，区间已经彻底崩坏。**R2 测错了维度** → 补 R4（§6.3）。

**更正③ · ood_agent 的 RMSE 判据是钝刀**
`addendum_metric_discriminability` 显示 ood_agent 的 `core_range/mean_ci_halfwidth = 1.41`
（对比 id 6.56、ood_action 7.01、ood_neuro 2.93）→ 该子集上单细胞 RMSE 几乎**没有分辨率**。
凡在 ood_agent 上以 RMSE 小数第 3 位判定成败的规则（含 §2 实验 6、以及 P4-3 的预锁判据）都须附此限定。

### 6.3 新增否决规则 R4（校准闸门）

> **R4 校准闸门**：任何预测器若 `ECE > 0.15` 或 `|覆盖@0.9 − 0.90| > 0.05`，
> 其预测区间**不得**用作任何实验的证伪标尺，也不得用于宣称「不确定度已覆盖」。
> 该预测器仍可参与点估计排名，但须显式标注「区间不可信」。

R4 的作用是把「点估计退化」与「区间失效」两类失效**分开记账**——这正是 R2 缺失的维度。
本周 R4 直接判废 `virtual_twin`（全域）、`knn`/`mean`（全域过覆盖）、以及两个孪生在 ood_action 上的区间。

### 6.4 P4-3 判决对湿实验的影响（本周新增证据）

`experiments/20260810-p43-shrinkage.json`：P4-3 经验贝叶斯逆方差收缩 **未通过**预锁判据（`P43_ACCEPTED=false`）。

- armC(P4-3) ood_agent RMSE **0.5881** [0.5839, 0.5924]，未达 ≤0.5854；var_ratio 0.4771（>0.10 达标）。
- 对比 armB(P4-2 等权) 0.5887 → Δ = **−0.00056**，CI 完全重叠 → 非显著。
- 机制诊断（独立于上述钝指标）：`τ² = 0.02820`、`SE² = 0.001676` → **τ²/SE² = 16.83**，
  隐含收缩系数 λ ≈ 0.944（实测 mean 0.931 / median 0.941）→ **收缩几乎是恒等映射**；
  相对等权平均的位移仅 **4.37%**，插补标准误仅降 **5.67%**。

**对湿实验的直接含义**：ood_agent 轴上「未见基因效应的插补精度」不是瓶颈——
基因间真实效应异质性（τ²）比抽样噪声（SE²）大 16.8×，说明**误差主体是加法先验的系统性偏差**，
而非「低证据基因把均值拉偏」。因此 **E5-novel-agent 不应再设计成「提高插补样本量/加权」类验证**，
而应转向检验「加法分解本身是否在该轴成立」（对应 P4-4 结构分离路线）。
